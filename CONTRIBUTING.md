You may use it as that license allows, with the mention it requires in your projects (*Made with Athanor (https://github.com/Aprilox/Athanor), created by Aprilox.* in their README and in a `NOTICE` file); changing it, reusing its code or sharing it needs Aprilox's written permission first.

## Asking for permission

Open an issue on [github.com/Aprilox/Athanor](https://github.com/Aprilox/Athanor/issues) titled **Permission request: …**, and say what you want to do (change the software, reuse part of its code, share it, a commercial use the license does not cover), for what purpose and for how long. A permission counts only once Aprilox has given it in writing, and only for what it says. Selling or distributing Athanor, or any work based on it, for a fee, and using its code to build a paid third-party tool, are reserved to Aprilox.

## Contributions

Issues (bugs, ideas) are welcome. A pull request is welcome too once Aprilox has agreed to it in an issue.

By submitting a contribution (a pull request, a patch, code or text in an issue), you grant Aprilox a perpetual, worldwide, non-exclusive, royalty-free and irrevocable license to use, reproduce, modify, distribute and sublicense it, and to publish it under any license, including for a fee; and you confirm that you have the right to grant it (the contribution is your own work, or you may contribute it under these terms).

# Contribuer à Athanor

Athanor est à source disponible, sous la licence PolyForm Strict 1.0.0 avec des conditions en plus (voir [LICENSE](LICENSE), dont le texte anglais fait foi). Vous pouvez l'utiliser comme cette licence le permet, avec la mention qu'elle exige dans vos projets (*Made with Athanor (https://github.com/Aprilox/Athanor), created by Aprilox.* dans leur README et dans un fichier `NOTICE`) ; le modifier, réutiliser son code ou le partager demande d'abord l'accord écrit d'Aprilox.

## Demander une autorisation

Ouvrez une issue sur [github.com/Aprilox/Athanor](https://github.com/Aprilox/Athanor/issues) intitulée **Permission request: …** et dites ce que vous voulez faire (modifier le logiciel, réutiliser une partie de son code, le partager, un usage commercial que la licence ne couvre pas), dans quel but et pour combien de temps. Une autorisation ne compte qu'une fois donnée par écrit par Aprilox, et seulement pour ce qu'elle dit. Vendre ou diffuser Athanor, ou toute œuvre qui en dérive, contre paiement, et se servir de son code pour faire un outil tiers payant, sont réservés à Aprilox.

## Contributions

Les issues (bugs, idées) sont les bienvenues. Une pull request aussi, une fois qu'Aprilox l'a acceptée dans une issue.

En soumettant une contribution (une pull request, un correctif, du code ou du texte dans une issue), vous accordez à Aprilox une licence perpétuelle, mondiale, non exclusive, gratuite et irrévocable de l'utiliser, la reproduire, la modifier, la distribuer et la sous-licencier, et de la publier sous toute licence, y compris contre paiement ; et vous confirmez avoir le droit de l'accorder (la contribution est votre propre travail, ou vous pouvez la proposer à ces conditions).
