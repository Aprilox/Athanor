## What's new in 2.28.1

- A small version to check the update from **Athanor.app** on the Mac: *Update now* downloads it, Athanor closes, puts it in place and opens again with its icon in the Dock. Running pilots go on.
- The checks of the Mac application pass on Windows too (Mac paths read the same on every system).

## Nouveautés de la 2.28.1
