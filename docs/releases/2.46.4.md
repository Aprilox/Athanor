## What's new in 2.46.4

- **A delivered project goes on with what you add.** Once a project was delivered, only a new request in the queue could reopen it: a note along the way, an edit of `REQUEST.md`, a milestone added to the plan or a task of *For you* answered was not seen, and *Start* ended at once, every time. Now the pilot reopens the delivery for any of them: the final report says `REOPENED`, a note or an edit becomes a milestone of the plan (with the lines added since the delivery), and a new delivery ends it. What reopened a delivery is taken in at once, so the same thing never reopens it twice (no cycles run for nothing).
- *Start* on a delivered project to which nothing was added says so, instead of a pilot that stops by itself; a note added to a delivered project says that *Start* takes it up. The Overview of a finished project says how to go on, in the window and in the terminal.

## Nouveautés de la 2.46.4

- **Un projet livré continue avec ce que vous ajoutez.** Une fois un projet livré, seule une nouvelle demande dans la file pouvait le rouvrir : une remarque en cours de route, une modification de `REQUEST.md`, un jalon ajouté au plan ou une tâche *Pour vous* répondue n'étaient pas vus, et *Démarrer* s'arrêtait aussitôt, à chaque fois. Maintenant, le pilote rouvre la livraison pour chacun d'eux : le rapport final dit `REOPENED`, une remarque ou une modification devient un jalon du plan (avec les lignes ajoutées depuis la livraison), et une nouvelle livraison le termine. Ce qui a rouvert une livraison est pris en compte aussitôt : la même chose ne la rouvre jamais deux fois (aucun cycle lancé pour rien).
- *Démarrer* sur un projet livré auquel rien n'a été ajouté le dit, au lieu d'un pilote qui s'arrête tout seul ; une remarque ajoutée à un projet livré dit que *Démarrer* la prend en compte. Le Suivi d'un projet terminé dit comment continuer, dans la fenêtre et dans le terminal.
