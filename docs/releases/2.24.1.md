## What's new in 2.24.1

- Verified MCP catalog: the Blender server's repository is shown at its real address (projects.blender.org), no longer as a GitHub path.
- Testing a server whose program is missing says which one and how to install it (e.g. `uvx`: install uv with `winget install --id astral-sh.uv -e`), instead of a bare "file not found".
- *Setup & health* (native Windows) also checks uv.

---

## Nouveautés de la 2.24.1

- Catalogue MCP vérifié : le dépôt du serveur Blender s'affiche à sa vraie adresse (projects.blender.org), et non plus comme un chemin GitHub.
- Tester un serveur dont le programme manque dit lequel et comment l'installer (par ex. `uvx` : installez uv avec `winget install --id astral-sh.uv -e`), au lieu d'un simple « fichier introuvable ».
- *Installation & santé* (Windows natif) vérifie aussi uv.
