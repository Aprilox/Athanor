## What's new in 2.24.0

- **The PC stays awake while a pilot runs**, in native Windows and WSL mode, the app closed or not (new setting *Keep the PC awake*, `KEEP_AWAKE`). For Roblox Studio and Unreal the screen stays on too: a locked Windows session draws nothing, so captures and play tests fail. `screen` keeps the screen on for every project, `0` turns it off.
- **A stopped cycle really stops in native Windows mode.** The watchdog (silent cycle, cycle too long, context full, quota "stop now") now ends the cycle through Athanor.exe's own PID, which stops every program of the cycle. If Claude still runs, the pilot keeps trying every minute, says so in the log, and never starts a second Claude beside it.
- **No more night lost on a capture.** Claude no longer loops on a Studio capture that fails: `roblox-studio --screen` tells whether the Windows session is locked; after one quick fix, Claude notes the problem in `BUGS.md` and goes on (a milestone that only lacks its screenshot is ticked, the screenshot stays pending). Waits of more than 2 minutes, and closing Roblox Studio or Unreal by program name (which would close yours too), are refused.
- The pilot's log says when the Windows session is locked during a Roblox Studio or Unreal cycle, and when it is unlocked again.
- **Blender in the verified MCP catalog**: Blender Lab's official server (Blender 5.1+ with its MCP add-on, uv and Git for Windows). The pilot opens Blender on the project's `.blend` before each cycle, and `blender --open` lets Claude open it.
- The native Windows installer (*Setup & health*) also installs uv.

## Nouveautés de la 2.24.0

- **Le PC reste éveillé tant qu'un pilote tourne**, en mode Windows natif comme en WSL, application ouverte ou fermée (nouveau réglage *Garder le PC éveillé*, `KEEP_AWAKE`). Pour Roblox Studio et Unreal, l'écran reste allumé aussi : une session Windows verrouillée n'affiche rien, donc les captures et les tests en jeu échouent. `screen` garde l'écran allumé pour tous les projets, `0` désactive.
- **Un cycle arrêté s'arrête vraiment en mode Windows natif.** La surveillance (cycle muet, cycle trop long, contexte plein, quota « arrêt immédiat ») arrête maintenant le cycle par le PID d'Athanor.exe lui-même, ce qui arrête tous les programmes du cycle. Si Claude tourne encore, le pilote réessaie chaque minute, le signale dans le journal et ne lance jamais un second Claude à côté.
- **Plus de nuit perdue sur une capture.** Claude ne boucle plus sur une capture Studio qui échoue : `roblox-studio --screen` indique si la session Windows est verrouillée ; après une correction rapide, Claude note le problème dans `BUGS.md` et continue (un jalon à qui il ne manque que sa capture est coché, la capture reste en attente). Les attentes de plus de 2 minutes, et la fermeture de Roblox Studio ou d'Unreal par nom de programme (qui fermerait aussi les vôtres), sont refusées.
- Le journal du pilote signale quand la session Windows est verrouillée pendant un cycle Roblox Studio ou Unreal, puis quand elle est déverrouillée.
- **Blender dans le catalogue MCP vérifié** : le serveur officiel de Blender Lab (Blender 5.1+ avec son module MCP, uv et Git pour Windows). Le pilote ouvre Blender sur le `.blend` du projet avant chaque cycle, et `blender --open` permet à Claude de l'ouvrir.
- L'installation du mode Windows natif (*Installation & santé*) installe aussi uv.
