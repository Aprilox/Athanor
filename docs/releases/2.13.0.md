## What's new in 2.13.0

- **Settings per MCP server**: a server that needs an address, a port, a host or a path shows it as a field next to its keys, in clear, with its default value. Athanor detects them by itself in a pasted configuration, in the MCP Registry and in plugins (their non-sensitive options); the verified catalog declares them.
- **Unreal Engine moves to the MCP library**: it is now a server of the verified catalog, installed once and switched on per project, with its address as a setting. The `UNREAL_MCP` settings of earlier versions are migrated automatically (server installed, switched on for your projects, address kept) and leave the Settings page.
- The *Sign in* button is shown only for servers hosted online.

---

## Nouveautés de la 2.13.0

- **Des réglages par serveur MCP** : un serveur qui a besoin d'une adresse, d'un port, d'un hôte ou d'un chemin l'affiche comme un champ à côté de ses clés, en clair, avec sa valeur par défaut. Athanor les détecte tout seul dans une configuration collée, dans le registre MCP et dans les plugins (leurs options non sensibles) ; le catalogue vérifié les déclare.
- **Unreal Engine passe dans la bibliothèque MCP** : c'est maintenant un serveur du catalogue vérifié, installé une fois et activé projet par projet, avec son adresse en réglage. Les réglages `UNREAL_MCP` des versions précédentes sont migrés automatiquement (serveur installé, activé pour vos projets, adresse conservée) et quittent la page Réglages.
- Le bouton *Se connecter* n'apparaît que pour les serveurs hébergés en ligne.
