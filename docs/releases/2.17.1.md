## What's new in 2.17.1

- **Fewer useless rechecks.** The pilot no longer closes a cycle right after a milestone commit while its full `check.sh` has not run yet: it waits for the `CHECK: PASSED` (20 min at most). It also finds that line in the check output files the lead writes (`.athanor/.verif/`, `.athanor/check-logs/`), not only in what it shows. A cycle that only updated the plan needs no check any more. The lead's instructions now run the full check before ticking and committing. Each of these cases used to cost a full check at the start of the next cycle.
- **The pilot picks serial or parallel for each cycle.** In parallel mode, the lead works alone for a cycle when workers would not pay off: fewer than 3 milestones ready at once, only documentation milestones (they link to each other and conflict), or the 5-hour quota at 75% or the weekly one at 85% (read from Claude Code's own rate-limit events). The log says why.
- **Complete costs for cycles closed by the pilot.** Their estimate now includes the sub-agents, read from the transcripts Claude Code keeps of them. The `≈` in the application no longer means "lead only".

## Nouveautés de la 2.17.1

- **Moins de revérifications inutiles.** Le pilote ne ferme plus un cycle juste après le commit d'un jalon tant que son `check.sh` complet n'a pas tourné : il attend le `CHECK: PASSED` (20 min au plus). Il trouve aussi cette ligne dans les fichiers de sortie du contrôle écrits par le chef (`.athanor/.verif/`, `.athanor/check-logs/`), pas seulement dans ce qu'il affiche. Un cycle qui n'a fait que mettre à jour le plan n'a plus besoin de contrôle. Les consignes du chef lancent maintenant le contrôle complet avant de cocher et de commiter. Chacun de ces cas coûtait un contrôle complet au début du cycle suivant.
- **Le pilote choisit entre série et parallèle à chaque cycle.** En mode parallèle, le chef travaille seul le temps d'un cycle quand des ouvriers ne seraient pas rentables : moins de 3 jalons prêts en même temps, uniquement des jalons de documentation (ils se citent entre eux et entrent en conflit), ou le quota des 5 heures à 75 % ou celui de la semaine à 85 % (lus dans les événements de limite de Claude Code). Le journal dit pourquoi.
- **Le coût complet des cycles fermés par le pilote.** L'estimation compte maintenant les sous-agents, lus dans les transcriptions que Claude Code en garde. Le `≈` de l'application ne veut plus dire « chef seul ».
