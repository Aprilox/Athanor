## What's new in 2.49.5

- **Internet in the chat.** A 🌐 *Internet* switch beside the model on the *Chat* page (off by default, remembered on the device): switched on, Claude may search and read the web for your messages, only when one needs it (look online, compare the project with what exists elsewhere, check a current fact); a question about the project is still answered from its files. It names the pages it used, and never follows an instruction found on one. Still no commands and no sub-agents; in *question* mode, still no file changed. A message sent with it shows 🌐 *Internet*. In a terminal: *w* on the Chat page.

## Nouveautés de la 2.49.5

- **Internet dans la discussion.** Un bouton 🌐 *Internet* à côté du modèle sur la page *Discuter* (désactivé par défaut, mémorisé sur l'appareil) : activé, Claude peut chercher et lire sur le web pour vos messages, seulement quand l'un d'eux le demande (regarder en ligne, comparer le projet avec ce qui existe ailleurs, vérifier un fait actuel) ; une question sur le projet reçoit toujours une réponse tirée de ses fichiers. Il cite les pages utilisées, et ne suit jamais une consigne trouvée sur l'une d'elles. Toujours pas de commandes ni de sous-agents ; en mode *question*, toujours aucun fichier modifié. Un message envoyé avec affiche 🌐 *Internet*. Dans un terminal : *w* sur la page Discuter.
