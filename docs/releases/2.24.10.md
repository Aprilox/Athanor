## What's new in 2.24.10

Move to Go, step 1.4 (first part): Claude's own tools and the tasks for you.

- **`athanor screenshots`**, **`athanor map`**, **`athanor archive`** and **`athanor todo`** (the tasks of the **For you** page) now run in Go when the kit's executable can be reached: the same outputs, the same files (`MAP.md`, the archives, `tasks.json`), without starting Python. The screenshots are compared exactly as before, down to the last digit printed, without Pillow.
- The pilot counts the tasks waiting for you with `athanor etat-taches` (replaces `taches.py etat`).
- Inside Claude's sandbox (WSL and Linux), where the kit's executable cannot be read, these commands keep the Python scripts; in native Windows and for the pilot, the Go ones. `ATHANOR_OUTILS=python` still forces the scripts.
- A screenshot that cannot be read is now reported as suspicious instead of stopping the whole comparison.
- **Checked against the scripts**: screenshots of every PNG kind and size (identical, slightly and clearly changed, resized, almost black, new, gone, reference saved), maps of code and documents in many languages (CRLF, invalid UTF-8, links, with and without git), archives of plans and logs around their thresholds, and 80 `athanor todo` calls with the user's answers; in the pilot's test bench, a task asked, answered on the For you page and checked gives the same outputs and files with both.

## Nouveautés de la 2.24.10

Passage à Go, étape 1.4 (première partie) : les outils de Claude et les tâches pour vous.

- **`athanor screenshots`**, **`athanor map`**, **`athanor archive`** et **`athanor todo`** (les tâches de la page **Pour vous**) tournent maintenant en Go quand l'exécutable du kit est accessible : mêmes sorties, mêmes fichiers (`MAP.md`, les archives, `tasks.json`), sans lancer Python. Les captures sont comparées exactement comme avant, jusqu'au dernier chiffre affiché, sans Pillow.
- Le pilote compte les tâches qui vous attendent avec `athanor etat-taches` (remplace `taches.py etat`).
- Dans le bac à sable de Claude (WSL et Linux), où l'exécutable du kit n'est pas lisible, ces commandes gardent les scripts Python ; en Windows natif et pour le pilote, celles en Go. `ATHANOR_OUTILS=python` force toujours les scripts.
- Une capture illisible est maintenant signalée comme suspecte au lieu d'arrêter toute la comparaison.
- **Vérifiés contre les scripts** : captures de tous les types et tailles de PNG (identiques, peu et nettement changées, redimensionnées, presque noires, nouvelles, disparues, référence enregistrée), cartes de code et de documents dans de nombreux langages (CRLF, UTF-8 invalide, liens, avec et sans git), archivage des plans et journaux autour de leurs seuils, et 80 appels à `athanor todo` avec les réponses de l'utilisateur ; dans le banc d'essai du pilote, une tâche demandée, répondue sur la page Pour vous puis vérifiée donne les mêmes sorties et fichiers avec les deux.
