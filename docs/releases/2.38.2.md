## What's new in 2.38.2

- **Commits on macOS without Claude as co-author**: the hook that removes Claude's co-author lines used `sed -i`, which macOS's `sed` reads differently: the hook failed and git refused every commit of the project. Since 2.38.0 ticks *Commit without Claude as co-author* by default, the pilots on a Mac could commit nothing. The hook is now portable, and never blocks a commit whatever happens; Athanor writes it again at the next start of a pilot.

## Nouveautés de la 2.38.2

- **Les commits sur macOS sans Claude en co-auteur** : le crochet qui retire les lignes de co-auteur de Claude utilisait `sed -i`, que le `sed` de macOS lit autrement : le crochet échouait et git refusait tous les commits du projet. Comme la 2.38.0 coche *Commiter sans Claude en co-auteur* par défaut, les pilotes sur Mac ne pouvaient plus rien commiter. Le crochet est maintenant portable, et ne bloque jamais un commit quoi qu'il arrive ; Athanor le réécrit au prochain démarrage d'un pilote.
