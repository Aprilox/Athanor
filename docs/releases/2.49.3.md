## What's new in 2.49.3

- **Already spent.** *Settings → Claude → Connection → Already spent* (API mode): what the API account has spent so far, say 20 $ of a 100 $ credit. The count starts from it when you save it: *Overview → API spend* then says 20 $ of 100 $, and the budget's pause compares the whole.
- **An automatic stop in dollars.** *Overview → API spend → Auto stop*, as for the subscription's quota: at 80 $, say, the pilot starts no new cycle once the spend reaches it, and stops (*Start* to go on, after raising or switching off the stop). The cost of a cycle is known at its end: the pilot stops after the cycle that reaches the amount, around it, never in the middle of a cycle. A mark on the bar shows it. In a terminal: *$* on the Overview, or `athanor depense arret 80` (`arret off`).

## Nouveautés de la 2.49.3

- **Déjà dépensé.** *Réglages → Claude → Connexion → Déjà dépensé* (mode API) : ce que le compte API a dépensé jusqu'ici, par exemple 20 $ d'un crédit de 100 $. Le décompte part de là quand vous l'enregistrez : *Suivi → Dépense API* affiche alors 20 $ sur 100 $, et la pause du budget compare le tout.
- **Un arrêt automatique en dollars.** *Suivi → Dépense API → Arrêt auto*, comme pour le quota de l'abonnement : à 80 $ par exemple, le pilote ne lance plus de nouveau cycle une fois la dépense atteinte, et s'arrête (*Démarrer* pour continuer, après avoir relevé ou désactivé l'arrêt). Le coût d'un cycle est connu à sa fin : le pilote s'arrête après le cycle qui atteint le montant, autour de lui, jamais au milieu d'un cycle. Une marque sur la barre le montre. Dans un terminal : *$* sur le Suivi, ou `athanor depense arret 80` (`arret off`).
