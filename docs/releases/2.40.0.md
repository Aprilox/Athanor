## What's new in 2.40.0

- **Athanor in a terminal** (Linux and macOS): `./athanor tui` shows the whole app in the terminal, like btop: the projects, the overview (the state of the pilot, the subscription quota, the cycles so far, the plan in waves), the live log with its filters, the requests (new, note along the way, delete, reorder), the chat, and Setup & health (check, repair, install). Start, Stop after cycle and Stop now ask the same questions as the window (no request yet, tools not installed, GitHub ahead). Keyboard and mouse; the app's palette, accent and language.
- **Opens by itself where there is no window**: through SSH, or on a Linux without a screen, `./athanor` alone opens the terminal interface. `./athanor gui` forces the window, in case the guess is wrong.
- **Alongside the window**: with Athanor already open, `./athanor tui` shows that same Athanor (both stay in step); in the terminal, *w* opens the window as well. When the terminal is the one that started Athanor, quitting it stops Athanor; the pilots keep running.
- **Repairs and the installation in front of you**: in the terminal, *Repair* and *Install everything* run right there, each command shown, sudo answered in the terminal, then Athanor comes back (no window to open on a server). *T* sets the token (after *Get a token*, it asks for it). The forms have *Save* and *Cancel* buttons, reached with Tab or a click; *F2* saves as well, for terminals that keep Ctrl+S.
- **Every page of daily use**: also *For you* (answer Claude's tasks, values in hidden fields), *Team*, *GitHub* (connect this computer right in the terminal, link or create a repository, push, automatic push, unlink), *Settings* (Athanor's settings, the language, the palette and the accent), managing a project (rename, archive and bring back, remove from the list) and the chat's model. Closing a form with text in it asks first.
- **On a server, a normal user**: Claude Code refuses to work as root; the *Linux* (or *macOS*) line of Setup & health now says so with the commands to create a user, and *Start* refuses with the same words. As root without sudo (a fresh server), *Install everything* runs its commands without sudo. A form the server refuses (a system folder for a project, say) stays open with the reason.
- **GitHub at every milestone**: the automatic push goes as soon as a milestone is committed, without waiting for the end of the cycle (the parallel verification merges several), and again at the end of every cycle when something is not on GitHub yet. Before, a milestone committed in a cycle cut by the context, the time limit or the quota waited for a later cycle with a commit of its own. With the automatic push off, the log now says so. The *Overview* shows the last commit of this computer and, under it, the last one on GitHub, with why the last push did not go.
- In the terminal, the letters of the *Settings* and *GitHub* pages come before the keys of every page, small or capital (*p* there is the palette or the push, no longer the project chooser). An Enter sent as CR LF by some terminals (its two halves arriving apart, through SSH) no longer saves at once the form it opens, and no longer answers the first launch's question by itself: the question waits for y or n.
- The in-app Guide has a new topic, *In a terminal*; `athanor aide` lists `tui` and `gui`.

## Nouveautés de la 2.40.0

- **Athanor dans un terminal** (Linux et macOS) : `./athanor tui` affiche toute l'application dans le terminal, comme btop : les projets, le suivi (l'état du pilote, le quota de l'abonnement, les cycles déjà faits, le plan en vagues), le journal en direct avec ses filtres, les demandes (nouvelle, remarque en cours de route, suppression, ordre), la discussion, et Installation & santé (vérifier, réparer, installer). Démarrer, Arrêter après le cycle et Arrêter maintenant posent les mêmes questions que la fenêtre (pas encore de demande, outils non installés, GitHub en avance). Clavier et souris ; la palette, l'accent et la langue de l'application.
- **S'ouvre d'elle-même là où il n'y a pas de fenêtre** : en SSH, ou sur un Linux sans écran, `./athanor` seul ouvre l'interface du terminal. `./athanor gui` force la fenêtre, au cas où la détection se tromperait.
- **À côté de la fenêtre** : avec Athanor déjà ouvert, `./athanor tui` montre ce même Athanor (les deux restent synchronisés) ; dans le terminal, *w* ouvre aussi la fenêtre. Quand c'est le terminal qui a lancé Athanor, le quitter arrête Athanor ; les pilotes continuent.
- **Les réparations et l'installation sous vos yeux** : dans le terminal, *Réparer* et *Tout installer* s'y déroulent, chaque commande affichée, sudo répondu dans le terminal, puis Athanor revient (aucune fenêtre à ouvrir sur un serveur). *T* règle le jeton (après *Obtenir un jeton*, il le demande). Les formulaires ont des boutons *Enregistrer* et *Annuler*, atteints avec Tab ou un clic ; *F2* enregistre aussi, pour les terminaux qui gardent Ctrl+S.
- **Toutes les pages du quotidien** : aussi *Pour vous* (répondre aux tâches de Claude, valeurs dans des champs masqués), *Équipe*, *GitHub* (connecter cet ordinateur directement dans le terminal, lier ou créer un dépôt, envoyer, envoi automatique, délier), *Réglages* (les réglages d'Athanor, la langue, la palette et l'accent), la gestion d'un projet (renommer, archiver et ramener, retirer de la liste) et le modèle de la discussion. Fermer un formulaire qui contient du texte demande d'abord.
- **Sur un serveur, un utilisateur normal** : Claude Code refuse de travailler en root ; la ligne *Linux* (ou *macOS*) d'Installation & santé le dit maintenant, avec les commandes pour créer un utilisateur, et *Démarrer* refuse avec les mêmes mots. En root sans sudo (un serveur neuf), *Tout installer* lance ses commandes sans sudo. Un formulaire refusé par le serveur (un dossier système pour un projet, par exemple) reste ouvert avec la raison.
- **GitHub à chaque jalon** : l'envoi automatique part dès qu'un jalon est commité, sans attendre la fin du cycle (la vérification parallèle en fusionne plusieurs), et de nouveau à la fin de chaque cycle quand quelque chose n'est pas encore sur GitHub. Avant, un jalon commité dans un cycle coupé par le contexte, la limite de temps ou le quota attendait un cycle suivant avec un commit à lui. Avec l'envoi automatique désactivé, le journal le dit maintenant. Le *Suivi* montre le dernier commit de cet ordinateur et, en dessous, le dernier sur GitHub, avec la raison quand le dernier envoi n'est pas parti.
- Dans le terminal, les lettres des pages *Réglages* et *GitHub* passent avant les touches de toutes les pages, en minuscule comme en majuscule (*p* y est la palette ou l'envoi, plus le choix du projet). Une Entrée envoyée en CR LF par certains terminaux (ses deux moitiés arrivant séparément, par SSH) n'enregistre plus aussitôt le formulaire qu'elle ouvre, et ne répond plus toute seule à la question du premier lancement : la question attend o ou n.
- Le Guide de l'application a un nouveau sujet, *Dans un terminal* ; `athanor aide` cite `tui` et `gui`.
