## What's new in 2.14.0

- **Local secrets never enter git**: the pilot excludes `.env` and its variants (`.env.local`, `.env.prod`…) before the first commit, so the *Initial commit* no longer picks them up. Their templates (`.env.example`, `.env.sample`, `.env.template`, `.env.dist`) stay committable.
- **The project's `.gitignore` lists them too**, added only when it does not mention `.env` already (and created if the project has none), so any copy of the project ignores them. A rule of your own (`*.env`, `!.env`…) is left as it is.
- **A `.env` git already follows is taken out of it**, kept on disk, in a commit of its own that never takes what you had staged. If it was already pushed (to GitHub or another remote), Claude adds a task on the *For you* page asking you to change the values it holds: they stay readable in the published history.

## Nouveautés de la 2.14.0

- **Les secrets locaux n'entrent plus dans git** : le pilote exclut `.env` et ses variantes (`.env.local`, `.env.prod`…) avant le premier commit, si bien que l'*Initial commit* ne les prend plus. Leurs modèles (`.env.example`, `.env.sample`, `.env.template`, `.env.dist`) restent commitables.
- **Le `.gitignore` du projet les liste aussi**, ajoutés seulement s'il ne mentionne pas déjà `.env` (et créé si le projet n'en a pas), pour qu'une copie du projet les ignore. Une règle à vous (`*.env`, `!.env`…) est laissée telle quelle.
- **Un `.env` que git suit déjà en est retiré**, conservé sur le disque, dans un commit à part qui ne prend jamais ce que vous aviez préparé. S'il avait déjà été poussé (sur GitHub ou un autre dépôt distant), Claude ajoute une tâche dans la page *Pour vous* pour vous demander d'en changer les valeurs : elles restent lisibles dans l'historique publié.
