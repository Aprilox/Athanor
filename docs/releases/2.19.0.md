## What's new in 2.19.0

- **Native Windows mode (experimental).** *Options → Execution mode → Native Windows*: the pilot runs in Git Bash (Git for Windows, the shell Claude Code uses on Windows) and Claude Code is the Windows program. No WSL, the project's Windows folder and Windows programs are reached directly, files are faster. **There is no sandbox in this mode**: Claude can read and change any file of the PC, Athanor's own settings included. The file guard and Claude's instructions keep it in the project, nothing more.
  - *Setup & health* has the checks of this mode, and *Install everything* installs what it needs with winget (Git for Windows, jq, Python, Node.js) and Claude Code for Windows.
  - Claude runs inside a Windows job (through Athanor.exe): stopping a cycle stops everything it started, and whatever it leaves running stops with it.
  - The project must be in a folder of a Windows drive. Its history (cycles, statistics) is the same in both modes. The mode applies to the pilots started afterwards.
  - Closing Athanor while native pilots run asks whether they go on in the background or stop.
- The WSL mode is unchanged and stays the default.

## Nouveautés de la 2.19.0

- **Mode Windows natif (expérimental).** *Options → Mode d'exécution → Windows natif* : le pilote tourne dans Git Bash (Git pour Windows, le shell que Claude Code utilise sous Windows) et Claude Code est le programme Windows. Pas de WSL, le dossier Windows du projet et les programmes Windows sont atteints directement, les fichiers sont plus rapides. **Il n'y a pas de barrière dans ce mode** : Claude peut lire et modifier n'importe quel fichier du PC, y compris les réglages d'Athanor. Le garde-fichiers et les consignes de Claude le gardent dans le projet, rien de plus.
  - *Installation et santé* a les vérifications de ce mode, et *Tout installer* installe ce qu'il lui faut avec winget (Git pour Windows, jq, Python, Node.js) et Claude Code pour Windows.
  - Claude tourne dans un job Windows (via Athanor.exe) : arrêter un cycle arrête tout ce qu'il a lancé, et ce qu'il laisse tourner s'arrête avec lui.
  - Le projet doit être dans un dossier d'un lecteur Windows. Son historique (cycles, statistiques) est le même dans les deux modes. Le mode s'applique aux pilotes lancés ensuite.
  - Fermer Athanor pendant que des pilotes natifs tournent demande s'ils continuent en arrière-plan ou s'arrêtent.
- Le mode WSL ne change pas et reste celui par défaut.
