## What's new in 2.31.0

- **Create a sub-agent by talking with Claude**: in *Chat*, describe the specialist you want ("a Blender specialist for the game's props"). Claude asks what it needs (what it does, when the lead calls it, what it must never do, the model, read only or not, its name), then shows the sub-agent as a card you can still edit, its instructions included (**✨ Improve with Claude** turns a few words, "beautiful retro textures, no errors", into complete instructions): **Add to the team** creates it, as the Team page does. It works while the pilot runs, since Claude writes nothing itself. Changing one of your sub-agents works the same way.
- **The checks of every push block on the three systems**: a failed test on Windows or macOS now turns the CI red (it was only informative), so it is seen before a version is tagged.

## Nouveautés de la 2.31.0

- **Créer un sous-agent en discutant avec Claude** : dans *Discuter*, décrivez le spécialiste voulu (« un spécialiste Blender pour les objets du jeu »). Claude pose ses questions (ce qu'il fait, quand le chef l'appelle, ce qu'il ne doit jamais faire, le modèle, lecture seule ou non, son nom), puis montre le sous-agent sous forme de fiche encore modifiable, consignes comprises (**✨ Améliorer avec Claude** transforme quelques mots, « de belles textures rétro, sans erreur », en consignes complètes) : **Ajouter à l'équipe** le crée, comme la page *Équipe*. Ça marche même pilote en cours, puisque Claude n'écrit rien lui-même. Modifier un de vos sous-agents se fait de la même façon.
- **Les vérifications de chaque push bloquent sur les trois systèmes** : un test raté sous Windows ou macOS met maintenant la CI en rouge (ce n'était qu'informatif), pour le voir avant de taguer une version.
