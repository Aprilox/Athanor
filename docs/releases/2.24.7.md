## What's new in 2.24.7

Move to Go, step 1.1: three helpers of the pilot are now Go sub-commands of the executable.

- **`athanor relais`** (taking over a milestone when a session's context is full), **`athanor cout`** (the prices learned on this PC and the cost of a cycle closed by the pilot) and **`athanor quota`** (the automatic stops on the subscription's quota) replace `relais.py`, `cout.py` and `quota.py`, with the same outputs and the same files.
- **Nothing can break**: the pilot uses them only when the kit's executable runs on this system and knows them (`Athanor.exe` in native Windows, `athanor` on Linux and in WSL); otherwise, or with `ATHANOR_OUTILS=python` in the settings, it keeps the Python scripts, as before. Its log says which ones it uses (`Helpers: Go …` or `Helpers: Python scripts.`).
- **Checked against the scripts**: tests compare both on the same logs (built for the test, and real logs of this PC), and the pilot's test bench runs the relay, the cost estimate, the quota stop and the parallel workers with each.
- The Windows download also holds `athanor`, the Linux build, for the pilots of the WSL mode.

## Nouveautés de la 2.24.7

Passage à Go, étape 1.1 : trois outils du pilote sont maintenant des sous-commandes Go de l'exécutable.

- **`athanor relais`** (reprendre un jalon quand le contexte d'une session est plein), **`athanor cout`** (les prix appris sur ce PC et le coût d'un cycle clos par le pilote) et **`athanor quota`** (les arrêts automatiques sur le quota de l'abonnement) remplacent `relais.py`, `cout.py` et `quota.py`, avec les mêmes sorties et les mêmes fichiers.
- **Rien ne peut casser** : le pilote ne s'en sert que si l'exécutable du kit tourne sur ce système et les connaît (`Athanor.exe` en Windows natif, `athanor` sous Linux et dans WSL) ; sinon, ou avec `ATHANOR_OUTILS=python` dans les réglages, il garde les scripts Python, comme avant. Son journal indique lesquels il utilise (`Helpers: Go …` ou `Helpers: Python scripts.`).
- **Vérifiés contre les scripts** : des tests comparent les deux sur les mêmes journaux (fabriqués pour le test, et de vrais journaux de ce PC), et le banc d'essai du pilote fait tourner le relais, l'estimation du coût, l'arrêt sur quota et les ouvriers parallèles avec chacun.
- Le téléchargement Windows contient aussi `athanor`, la version Linux, pour les pilotes du mode WSL.
