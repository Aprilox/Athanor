## What's new in 3.1.1

- **A mission's API keys, however many**: in the New mission form, *API keys for this mission* shows the chosen keys as chips (× removes one) and *Find an API* to add one, by its name, its type or its category, with the filter by category once you made some. The long list of boxes is gone, and a key named with `@` in the goal is added the same way.
- **New project as in 2.x**: the form on the left, GitHub in it, and the project's settings (working mode, longest framing, work time limit, models) in their own column on the right, nothing folded; under the form on a narrow window.
- **An animated mark on the home page**: an empty conversation draws Athanor's logo in your theme's colours, as in the opening scene, then its cycle turns slowly. Still when the animation is off in Settings or the system asks for less motion.

## Nouveautés de la 3.1.1

- **Les clés API d'une mission, quel que soit leur nombre** : dans le formulaire Nouvelle mission, *Clés API de la mission* montre les clés choisies en puces (× en retire une) et *Chercher une API* pour en ajouter une, par son nom, son type ou sa catégorie, avec le filtre par catégorie dès que vous en avez créé. La longue liste de cases disparaît, et une clé nommée par `@` dans le but s'ajoute de la même façon.
- **Nouveau projet comme en 2.x** : le formulaire à gauche, GitHub dedans, et les réglages du projet (mode de travail, cadrage le plus long, limite de temps de travail, modèles) dans leur propre colonne à droite, rien de replié ; sous le formulaire sur une fenêtre étroite.
- **Une marque animée sur l'accueil** : une conversation vide dessine le logo d'Athanor aux couleurs de votre thème, comme dans la scène d'ouverture, puis son cycle tourne doucement. Immobile quand l'animation est désactivée dans les Réglages ou que le système demande moins de mouvement.
