## What's new in 2.16.1

- **True costs for every cycle.** When the pilot closes a cycle right after its milestone, or a cycle is stopped, Claude Code writes no cost. Those cycles showed 0 $, which made the totals look lower than they were. The pilot now works their cost out from the lead's turns, each message counted once. It uses the prices of each model learned from this PC's own results (`logs/tarifs.json`, never written by hand, since prices change). The application shows these costs with `≈`; they leave out the sub-agents, so they are a floor. A model whose price is not learned yet shows `?`.
- The token counts of those cycles were counted up to twice: fixed.

## Nouveautés de la 2.16.1

- **Le vrai coût de chaque cycle.** Quand le pilote ferme un cycle juste après son jalon, ou qu'un cycle est arrêté, Claude Code n'écrit aucun coût. Ces cycles affichaient 0 $, et les totaux paraissaient plus bas qu'en réalité. Le pilote calcule maintenant leur coût à partir des tours du chef, chaque message compté une seule fois. Il utilise les prix de chaque modèle appris à partir des résultats de ce PC (`logs/tarifs.json`, jamais écrit à la main, car les prix changent). L'application affiche ces coûts avec `≈` ; ils ne comptent pas les sous-agents, c'est donc un minimum. Un modèle dont le prix n'est pas encore appris affiche `?`.
- Les tokens de ces cycles étaient comptés jusqu'à deux fois : corrigé.
