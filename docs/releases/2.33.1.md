## What's new in 2.33.1

- **Several computers, on Windows**: a computer that joins a team from a new folder, with Athanor on Windows itself (not WSL), now writes the project's files with the line endings its pilot keeps. Before, every file looked changed once the pilot started, so the others' work could not come in and that computer wrote the plan a second time.
- A computer whose project has changes not committed waits for them before building, when the team's plan has not reached it yet, instead of writing a plan of its own.

---

## Nouveautés de la 2.33.1

- **Plusieurs ordinateurs, sous Windows** : un ordinateur qui rejoint une équipe depuis un nouveau dossier, avec Athanor sous Windows même (pas WSL), écrit maintenant les fichiers du projet avec les fins de ligne que garde son pilote. Avant, tous les fichiers paraissaient modifiés dès le démarrage du pilote : le travail des autres ne pouvait plus entrer, et cet ordinateur réécrivait le plan.
- Un ordinateur dont le projet a des changements non commités les attend avant de construire, quand le plan de l'équipe ne lui est pas encore parvenu, au lieu d'écrire un plan à lui.
