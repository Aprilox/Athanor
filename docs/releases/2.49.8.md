## What's new in 2.49.8

- **No more console windows on your screen (native Windows).** Claude Code starts some programs without a console of their own, its MCP servers first (cmd, npx, node, Roblox Studio's `mcp.bat`): each one opened a window of its own, a console or a Windows Terminal, often a PowerShell one, at every start and end of a session. Now:
  - The MCP servers are started through Athanor, their console hidden, on the desktop Claude runs on. Whatever a server leaves running stops with it.
  - Claude Code's PowerShell tool is off in the native mode: it opened a window at each command, outside the hooks that check Claude's commands (and RTK). Claude runs PowerShell from Git Bash, as before.
  - A guard watches the windows that appear while a pilot or the application runs: a console or a Windows Terminal opened by a program Athanor started is hidden at once, and the program goes on without it. The pilot's *Log* says which one (*a window of node.exe (started by cmd.exe)… hidden*), and the application's own go to `logs\fenetres-masquees.log`. The windows Athanor opens on purpose (installation, sign-in, token) and your own are never touched.

## Nouveautés de la 2.49.8

- **Plus de fenêtres de console sur votre écran (Windows natif).** Claude Code lance certains programmes sans console à eux, ses serveurs MCP en premier (cmd, npx, node, le `mcp.bat` de Roblox Studio) : chacun ouvrait une fenêtre à lui, une console ou un Terminal Windows, souvent un PowerShell, à chaque début et fin de session. Désormais :
  - Les serveurs MCP sont lancés par Athanor, leur console masquée, sur le bureau où Claude travaille. Ce qu'un serveur laisse tourner s'arrête avec lui.
  - L'outil PowerShell de Claude Code est désactivé en mode natif : il ouvrait une fenêtre à chaque commande, hors des crochets qui vérifient les commandes de Claude (et RTK). Claude lance PowerShell depuis Git Bash, comme avant.
  - Une garde surveille les fenêtres qui apparaissent pendant qu'un pilote ou l'application tourne : une console ou un Terminal Windows ouvert par un programme qu'Athanor a lancé est masqué aussitôt, et le programme continue sans. Le *Journal* du pilote dit lequel (*a window of node.exe (started by cmd.exe)… hidden*), et ceux de l'application vont dans `logs\fenetres-masquees.log`. Les fenêtres qu'Athanor ouvre exprès (installation, connexion, jeton) et les vôtres ne sont jamais touchées.
