## What's new in 2.24.5

First step of the move to Go (one executable per system, Windows, Linux and macOS):

- **Sub-commands**: `athanor version`, `athanor aide` (the list), `athanor isole`, `athanor eveil`, `athanor retour`. The older `--isole`, `--eveil` and `--retour` stay valid, so nothing changes for the pilots and gateways. The scripts that move to Go in the next versions become more of these sub-commands.
- **Every target builds**: `./build.sh --all` builds Windows, Linux and macOS, x86-64 and ARM, into `dist/`.
- **Checks on the three systems**: every push runs the Go checks and tests on Windows, Linux and macOS, builds every target and checks the syntax of the remaining scripts (`.github/workflows/ci.yml`).

Nothing changes in how Athanor works.

## Nouveautés de la 2.24.5

Première étape du passage à Go (un seul exécutable par système, Windows, Linux et macOS) :

- **Sous-commandes** : `athanor version`, `athanor aide` (la liste), `athanor isole`, `athanor eveil`, `athanor retour`. Les anciennes `--isole`, `--eveil` et `--retour` restent valables : rien ne change pour les pilotes et les passerelles. Les scripts qui passeront en Go dans les prochaines versions deviendront d'autres sous-commandes.
- **Toutes les cibles se compilent** : `./build.sh --all` compile Windows, Linux et macOS, x86-64 et ARM, dans `dist/`.
- **Vérifications sur les trois systèmes** : chaque push lance les vérifications et les tests Go sous Windows, Linux et macOS, compile toutes les cibles et vérifie la syntaxe des scripts restants (`.github/workflows/ci.yml`).

Rien ne change dans le fonctionnement d'Athanor.
