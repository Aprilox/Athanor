## What's new in 2.51.0

- **Files in the chat**: *Attach files* under the chat's field (or drop them there, or paste a screenshot in the field). They go into the project's workshop (`.athanor/attachments/chat/`) and Claude reads them, images included. A note Claude writes for the pilot names them, so the pilot gets the image too.
- **Changes while the pilot runs**: tick *change the files (the pilot pauses)*. Athanor tells you what happens and asks first: the pilot stops at the end of its current cycle (*Restart requested* shows at the top), Claude makes the change, Athanor commits it, and the pilot starts again on its own, with a note in its request naming the change. *Stop* in the chat, or cancelling the stop at the top, gives the change up and the pilot goes on. With the pilot stopped, nothing changes: Claude changes the files and the pilot stays stopped.
- **An MCP server from the chat**: ask Claude to connect a program. It looks for an existing server (with *Internet* on: the official MCP Registry, the program's documentation, GitHub), or writes one when there is none (a Python file run by uv). It shows a card you can still edit; *Add to the library* installs it and switches it on in the project. The files of a server Claude wrote are kept in `tools/mcp-ecrits/`. Its keys are filled in on the *Skills & MCP* page, where *Test* and *Fix with Claude* work as for any server.

## Nouveautés de la 2.51.0

- **Des fichiers dans Discuter** : *Joindre des fichiers* sous le champ de la discussion (ou les déposer là, ou coller une capture d'écran dans le champ). Ils vont dans l'atelier du projet (`.athanor/attachments/chat/`) et Claude les lit, images comprises. Une note que Claude rédige pour le pilote les cite, et le pilote a donc l'image lui aussi.
- **Des modifications pendant que le pilote tourne** : cochez *modifier les fichiers (le pilote fait une pause)*. Athanor vous explique ce qui va se passer et demande d'abord : le pilote s'arrête à la fin de son cycle en cours (*Redémarrage demandé* s'affiche en haut), Claude fait la modification, Athanor la commite, puis le pilote repart seul, avec une remarque dans sa demande sur le changement. *Arrêter* dans Discuter, ou l'annulation de l'arrêt en haut, abandonne la modification et le pilote continue. Pilote arrêté, rien ne change : Claude modifie les fichiers et le pilote reste arrêté.
- **Un serveur MCP depuis Discuter** : demandez à Claude de relier un logiciel. Il cherche un serveur existant (avec *Internet* : le registre MCP officiel, la documentation du logiciel, GitHub), ou en écrit un s'il n'y en a pas (un fichier Python lancé par uv). Il affiche une carte encore modifiable ; *Ajouter à la bibliothèque* l'installe et l'active dans le projet. Les fichiers d'un serveur écrit par Claude sont gardés dans `tools/mcp-ecrits/`. Ses clés se remplissent sur la page *Skills & MCP*, où *Tester* et *Corriger avec Claude* marchent comme pour tout serveur.
