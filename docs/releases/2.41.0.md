## What's new in 2.41.0

- **Eco mode**, per project (*Manage → Working mode*, or **M** then *Working mode* in a terminal): for when the quota matters more than speed. Measured on a real game project, sub-agents used 80 to 87 % of the tokens: in the eco mode the lead does the work itself, the project's sub-agents run only when the request asks for them on that milestone, `critic` and `tester` run once, at delivery (no counter-review), the framing skips the scouts and the plan review, at most 4 image reads per cycle, command outputs cut at 8,000 characters. The model and the thinking effort stay as you set them; the switch suggests a smaller model and a lower effort to save even more.
- The eco mode and the parallel mode never run together: switching one on switches the other off (and a pilot finding both in `.athanor/.env` runs the eco mode).
- The Overview shows *eco mode* while a cycle runs.
- The terminal interface can now choose the working mode too (one milestone at a time, parallel, eco), from *Manage*.

## Nouveautés de la 2.41.0

- **Mode éco**, par projet (*Gérer → Mode de travail*, ou **M** puis *Mode de travail* dans un terminal) : pour quand le quota compte plus que la vitesse. Mesuré sur un vrai projet de jeu, les sous-agents consommaient 80 à 87 % des jetons : en mode éco, le chef fait le travail lui-même, les sous-agents du projet ne passent que si la demande les exige pour ce jalon, `critic` et `tester` passent une seule fois, à la livraison (pas de contre-revue), le cadrage se passe des éclaireurs et de la relecture du plan, 4 lectures d'image au plus par cycle, des sorties de commandes coupées à 8 000 caractères. Le modèle et l'effort de réflexion restent tels que vous les avez réglés ; l'interrupteur conseille un modèle plus petit et un effort plus bas pour économiser encore plus.
- Le mode éco et le mode parallèle ne tournent jamais ensemble : activer l'un coupe l'autre (et un pilote qui trouve les deux dans `.athanor/.env` fait tourner le mode éco).
- Le Suivi affiche *mode éco* pendant un cycle.
- L'interface en terminal peut maintenant choisir le mode de travail elle aussi (un jalon à la fois, parallèle, éco), depuis *Gérer*.
