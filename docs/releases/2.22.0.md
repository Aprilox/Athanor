## What's new in 2.22.0

- **Chat with Claude** (new *Chat* page): ask about the project without opening Claude yourself.
  - Questions at any time: Claude reads the code, the plan and the log, and answers. The conversation goes on from one message to the next.
  - While the pilot is stopped, Claude can also change the project's files (no commands), and Athanor commits the change ("Chat: …"). *Question only* keeps it read-only.
  - While the pilot runs, Claude changes nothing: it writes the change as a note for the pilot, and *Send to the pilot* adds it to the notes the pilot reads at its next cycle.
  - The model is picked in the chat. Claude's file tools stay inside the project, as for the pilot.
- **Overview**:
  - *Subscription quota*: the current 5-hour session, the week, and a model's own week (Fable) when your plan has one, with how much is used and when it resets, as Claude Code last reported it.
  - *Progress*: a chart of the milestones done over time, the projection to the last milestone, with its estimated time and cost, and the cost of each cycle.
- **Settings**: the model proposals are those of before, but no longer a fixed list: the aliases (opus, sonnet, haiku, fable: always the newest model of their family), then the models this PC has used, so a new model appears by itself. The explanations no longer list model names.

## Nouveautés de la 2.22.0

- **Discuter avec Claude** (nouvelle page *Discuter*) : poser des questions sur le projet sans ouvrir Claude vous-même.
  - Des questions à tout moment : Claude lit le code, le plan et le journal, et répond. La conversation continue d'un message à l'autre.
  - Pilote arrêté, Claude peut aussi modifier les fichiers du projet (sans commandes), et Athanor commite la modification (« Chat: … »). *Question seulement* le garde en lecture.
  - Pilote en marche, Claude ne change rien : il écrit la modification sous forme de remarque pour le pilote, et *Envoyer au pilote* l'ajoute aux remarques que le pilote lit à son prochain cycle.
  - Le modèle se choisit dans la discussion. Les outils de fichiers de Claude restent dans le projet, comme pour le pilote.
- **Suivi** :
  - *Quota de l'abonnement* : la session de 5 h en cours, la semaine, et la semaine propre à un modèle (Fable) si votre abonnement en a une, avec ce qui est utilisé et l'heure de réinitialisation, tels que Claude Code les a indiqués en dernier.
  - *Avancement* : un graphique des jalons terminés dans le temps, la projection jusqu'au dernier jalon avec son heure et son coût estimés, et le coût de chaque cycle.
- **Réglages** : les propositions de modèles sont celles d'avant, mais plus une liste figée : les alias (opus, sonnet, haiku, fable : toujours le modèle le plus récent de leur famille), puis les modèles que ce PC a utilisés, donc un nouveau modèle apparaît de lui-même. Les explications ne listent plus de noms de modèles.
