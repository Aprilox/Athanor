## What's new in 2.51.8

- **A work time limit instead of a safety stop**: the limit (MAX_HOURS) now counts only the time the pilot works. Its waits (quota, errors, the For you page), a pause, a stopped pilot or Athanor closed no longer count: three hours of work, then a week stopped, then three more hours make six hours. Until now, the time since the project's first start counted, so a project paused for a week could not start again. The count starts with this version.
- **Unlimited by default**: a new installation has no time limit; the pilot works until the project is delivered, which stops it by itself. A limit only caps what a project can use, in Settings or project by project (Manage › Working mode). An existing setting is kept as it is.
- **Its name and its explanations say so**: "Work time limit" in Settings, in the project's Working mode and in the terminal setup, with an "i" that explains what counts, in every language.

## Nouveautés de la 2.51.8

- **Une limite de temps de travail au lieu d'un arrêt de sécurité** : la limite (MAX_HOURS) ne compte plus que le temps où le pilote travaille. Ses attentes (quota, erreurs, page Pour vous), une pause, un pilote arrêté ou Athanor fermé ne comptent plus : trois heures de travail, puis une semaine à l'arrêt, puis trois heures encore font six heures. Jusqu'ici, c'était le temps depuis le premier démarrage du projet qui comptait, si bien qu'un projet mis en pause une semaine ne pouvait plus repartir. Le décompte commence avec cette version.
- **Illimitée par défaut** : une nouvelle installation n'a pas de limite de temps ; le pilote travaille jusqu'à la livraison du projet, qui l'arrête d'elle-même. Une limite sert seulement à plafonner ce qu'un projet peut consommer, dans les Réglages ou projet par projet (Gérer › Mode de travail). Un réglage déjà choisi est gardé tel quel.
- **Son nom et ses explications le disent** : « Limite de temps de travail » dans les Réglages, dans le Mode de travail du projet et dans l'assistant en terminal, avec un « i » qui explique ce qui compte, dans toutes les langues.
