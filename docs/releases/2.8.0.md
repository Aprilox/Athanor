## What's new in 2.8.0

### GitHub, automatically
- **Link a project to GitHub** when you create it, or later under *Manage*: a new private repository, or one of yours.
- **A push after each milestone** and at the delivery, by itself (or only when you click *Push now*). The *Manage* page shows the last push, its commit and what went wrong if anything did.
- **One repository, one key**: a window opens once to sign in to GitHub; Athanor gives the repository its own key, valid for that repository alone, then signs out. No GitHub sign-in is kept on your PC, the key stays out of Claude's reach, and nothing Claude writes in the project can redirect a push.
- **Never forced, never a secret**: if GitHub has commits the project does not, nothing is overwritten. Keys, tokens, `.env` files and private keys found in the new commits stop the push, and Claude removes them from the unpushed commits on its next cycle (or push anyway if it is a false alarm). A change to GitHub Actions workflows waits for your OK.

- **Your name on the commits**: choose the author (name, GitHub email or private noreply address, proposed from your account) and commit without Claude as co-author. Commit subjects follow one clear format: `M3: what the milestone delivers`.

### Also
- On Linux, the steps that need a window (installation, repairs, GitHub sign-in) open in a terminal of your desktop.
- Only the windows Athanor opens can use the app: a program of the computer that finds its port gets neither the page nor its API.
- Reloading the app on a page no longer shows the Overview by mistake.

## Nouveautés de la 2.8.0

### GitHub, automatiquement
- **Liez un projet à GitHub** à sa création, ou plus tard dans *Gérer* : un nouveau dépôt privé, ou un des vôtres.
- **Un envoi après chaque jalon** et à la livraison, tout seul (ou seulement quand vous cliquez *Envoyer maintenant*). La page *Gérer* montre le dernier envoi, son commit et ce qui n'a pas marché le cas échéant.
- **Un dépôt, une clé** : une fenêtre s'ouvre une seule fois pour se connecter à GitHub ; Athanor donne au dépôt sa propre clé, valable pour ce dépôt seulement, puis se déconnecte. Aucune connexion GitHub n'est gardée sur votre PC, la clé reste hors de portée de Claude, et rien de ce que Claude écrit dans le projet ne peut détourner un envoi.
- **Jamais forcé, jamais de secret** : si GitHub a des commits que le projet n'a pas, rien n'est écrasé. Les clés, jetons, fichiers `.env` et clés privées trouvés dans les nouveaux commits bloquent l'envoi, et Claude les retire des commits non envoyés à son cycle suivant (ou envoyez quand même s'il s'agit d'une fausse alerte). Une modification des workflows GitHub Actions attend votre accord.

- **Votre nom sur les commits** : choisissez l'auteur (nom, email GitHub ou adresse privée noreply, proposés depuis votre compte) et commitez sans Claude en co-auteur. Les titres de commit suivent un format clair : `M3: ce que le jalon apporte`.

### Aussi
- Sous Linux, les étapes qui demandent une fenêtre (installation, réparations, connexion GitHub) s'ouvrent dans un terminal de votre bureau.
- Seules les fenêtres qu'Athanor ouvre peuvent utiliser l'application : un programme de l'ordinateur qui trouve son port n'obtient ni la page ni son API.
- Recharger l'application sur une page n'affiche plus le Suivi par erreur.
