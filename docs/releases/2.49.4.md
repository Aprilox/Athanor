## What's new in 2.49.4

- **The chat counted once in the API spend.** Each message of the *Chat* page resumes the same Claude session, and Claude Code then reports the total of the whole conversation so far, not the cost of the message: that total was added again at every message, and the API spend grew far faster than the API account's own (about 42 $ too many over six messages). Each message now counts the difference with the total before it, in the API spend and under the answer on the *Chat* page. The cycles were counted right. To set the count right again: *Overview → API spend → Count again from now*, then *Settings → Claude → Already spent* with what console.anthropic.com shows.

## Nouveautés de la 2.49.4

- **La discussion comptée une seule fois dans la dépense API.** Chaque message de la page *Discuter* reprend la même session de Claude, et Claude Code donne alors le total de toute la conversation jusque-là, pas le coût du message : ce total était ajouté de nouveau à chaque message, et la dépense API grimpait bien plus vite que celle du compte API (environ 42 $ de trop sur six messages). Chaque message compte maintenant la différence avec le total d'avant, dans la dépense API et sous la réponse de la page *Discuter*. Les cycles étaient bien comptés. Pour recaler le compteur : *Suivi → Dépense API → Recompter à partir de maintenant*, puis *Réglages → Claude → Déjà dépensé* avec ce qu'affiche console.anthropic.com.
