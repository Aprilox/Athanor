## What's new in 2.24.2

- A program's MCP server switched on in the app during a run (Blender, Roblox Studio, Unreal) now has its program opened by the pilot at the very next cycle; it used to wait one more cycle.
- Blender MCP: when a Blender tool answers "Cannot connect to Blender", Claude opens Blender itself with `blender --open` (on Claude's desktop when that option is on), then tries again.
- The MCP page shows repositories outside GitHub at their real address.

---

## Nouveautés de la 2.24.2

- Un serveur MCP de programme activé dans l'application en cours de route (Blender, Roblox Studio, Unreal) a maintenant son programme ouvert par le pilote dès le cycle suivant ; il fallait attendre un cycle de plus.
- MCP Blender : quand un outil Blender répond « Cannot connect to Blender », Claude ouvre Blender lui-même avec `blender --open` (sur le bureau de Claude si cette option est activée), puis réessaie.
- La page MCP affiche les dépôts hors GitHub à leur vraie adresse.
