## What's new in 2.49.2

- **Every run of Claude counted in the API spend.** The short ones were left out: *Setup & health*'s check of the connection (a tiny Haiku session), *Fix with Claude* (an MCP server, a skill) and *Improve with Claude* (the request). They now read Claude Code's JSON answer and write what they cost, like the cycles and the chat: in API mode, the spend and the budget's pause count them too.

---

## Nouveautés de la 2.49.2

- **Chaque passage de Claude compté dans la dépense API.** Les courts étaient oubliés : la vérification de la connexion d'*Installation & santé* (une mini-session Haiku), *Corriger avec Claude* (un serveur MCP, une skill) et *Améliorer avec Claude* (la demande). Ils lisent maintenant la réponse JSON de Claude Code et notent ce qu'ils coûtent, comme les cycles et la discussion : en mode API, la dépense et la pause du budget les comptent aussi.
