## What's new in 2.39.1

- **Updating while a pilot runs, said plainly**: an update goes on applying to the app at once, and a running pilot goes on without a break on the version it started with. The app now says so: *Update now* lists the pilots running and tells they move to the new version the next time they start (*Stop after cycle*, then *Start*); after the update, *Overview → Right now* shows "This pilot keeps running on 2.39.0, the version it started with…" until it starts again. In WSL mode, the message after the update says the same, reassuringly: the update is installed, nothing to do.
- A pilot now notes its version in its workshop (`.athanor/pilot.version`, never shared on GitHub nor copied with the workshop), removed when it stops.

## Nouveautés de la 2.39.1

- **Mettre à jour pendant qu'un pilote tourne, dit clairement** : une mise à jour s'applique toujours tout de suite à l'application, et un pilote en cours continue sans interruption sur la version avec laquelle il a démarré. L'application le dit maintenant : *Mettre à jour maintenant* liste les pilotes en cours et précise qu'ils passent à la nouvelle version à leur prochain démarrage (*Arrêter après le cycle*, puis *Démarrer*) ; après la mise à jour, *Suivi → Maintenant* affiche « Ce pilote continue sur la 2.39.0, la version avec laquelle il a démarré… » jusqu'à ce qu'il redémarre. En mode WSL, le message qui suit la mise à jour dit la même chose, de façon rassurante : la mise à jour est installée, rien à faire.
- Un pilote note maintenant sa version dans son atelier (`.athanor/pilot.version`, jamais partagé sur GitHub ni copié avec l'atelier), retiré quand il s'arrête.
