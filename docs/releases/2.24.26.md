## What's new in 2.24.26

The Go pilot gets a safety net before it becomes the default: if it ever fails, the bash pilot carries on the same night.

- **An internal error of the Go pilot no longer stops the work.** The Go pilot (`PILOT_ENGINE=go`) now runs under `pilot.sh`: when it hits an error of its own (a Go panic), it first stops what it started (Claude's session, the workers and their worktrees, the bridge, the Rojo sync), keeps its report in `logs/pilotes/…/pilote-go.crash`, and the bash pilot takes over at once: "The Go pilot stopped on an internal error (…): the bash pilot carries on." Even a fatal error that nothing can catch is handled: its report is kept, the session it left is stopped, and the bash pilot carries on.
- **An ordinary end stays an ordinary end**: a stop, the end of the plan or STOP leave no report and start nothing else.
- **Checked**: a Go pilot killed in the middle of a cycle (its Claude session stopped, the work carried on in bash, a clean exit), a panic in one of its goroutines (exit 70, report, session stopped, lock and pilot.pid released), an ordinary end; the 41 scenarios run with both engines again, the Go tests.

## Nouveautés de la 2.24.26

Le pilote Go reçoit un filet de sécurité avant de passer par défaut : s'il échoue un jour, le pilote bash continue la même nuit.

- **Une erreur interne du pilote Go n'arrête plus le travail.** Le pilote Go (`PILOT_ENGINE=go`) tourne désormais sous `pilot.sh` : s'il rencontre une erreur à lui (une panique Go), il arrête d'abord ce qu'il a lancé (la session de Claude, les ouvriers et leurs worktrees, la passerelle, la synchro Rojo), garde son rapport dans `logs/pilotes/…/pilote-go.crash`, et le pilote bash prend le relais aussitôt : « The Go pilot stopped on an internal error (…): the bash pilot carries on. » Même une erreur fatale que rien ne peut rattraper est gérée : son rapport est gardé, la session qu'elle a laissée est arrêtée, et le pilote bash continue.
- **Une fin normale reste une fin normale** : un arrêt, la fin du plan ou STOP ne laissent aucun rapport et ne lancent rien d'autre.
- **Vérifié** : un pilote Go tué au milieu d'un cycle (sa session Claude arrêtée, le travail poursuivi en bash, une sortie propre), une panique dans l'une de ses goroutines (sortie 70, rapport, session arrêtée, verrou et pilot.pid libérés), une fin normale ; les 41 scénarios rejoués avec les deux moteurs, les tests Go.
