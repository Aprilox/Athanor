## What's new in 2.24.18

GitHub moves to Go (the move of Athanor to Go, step 2.2).

- **`athanor github`** now does all of `system/github.sh` in WSL and on Linux: the state shown in the app, the push after each milestone (secret check, push anyway, protected or ahead branches, network fallback), the settings (automatic push, branch), the author of the commits, unlinking, and the link following a project folder that moved. The same files in the same place, the same messages and exit codes, the same lock as the script (a push and a link never run at once).
- Linking a project (the GitHub sign-in in a window) stays in the script, and native Windows keeps the script; both use the Go secret check of 2.24.17. `ATHANOR_OUTILS=python` still forces the scripts.
- **Checked**: every command side by side with the script, on real pushes to a local SSH server standing for GitHub: secrets found and pushed anyway, up to date, workflows, a branch ahead on GitHub, a missing repository, no commit yet, a `.git` pointing elsewhere, the state and the author for the app, settings, moving and unlinking; the validators and the settings reader against bash itself.

## Nouveautés de la 2.24.18

GitHub passe en Go (passage d'Athanor en Go, étape 2.2).

- **`athanor github`** fait maintenant tout `system/github.sh` sous WSL et Linux : l'état affiché dans l'appli, le push après chaque jalon (vérification des secrets, pousser quand même, branche protégée ou en avance, réseau de secours), les réglages (push automatique, branche), l'auteur des commits, la déliaison, et le lien qui suit un dossier de projet déplacé. Mêmes fichiers au même endroit, mêmes messages et codes de sortie, même verrou que le script (un push et une liaison ne tournent jamais en même temps).
- La liaison d'un projet (la connexion à GitHub dans une fenêtre) reste dans le script, et Windows natif garde le script ; les deux utilisent la vérification des secrets en Go de la 2.24.17. `ATHANOR_OUTILS=python` force toujours les scripts.
- **Vérifié** : chaque commande côte à côte avec le script, sur de vrais push vers un serveur SSH local qui joue GitHub : secrets trouvés puis poussés quand même, à jour, workflows, branche en avance sur GitHub, dépôt absent, pas encore de commit, `.git` qui pointe ailleurs, l'état et l'auteur pour l'appli, réglages, déplacement et déliaison ; les validateurs et la lecture des réglages contre bash lui-même.
