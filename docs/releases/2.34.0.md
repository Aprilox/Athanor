## What's new in 2.34.0

- **A Guide page, always in the menu**: step-by-step tutorials to start a project, link it to GitHub, follow it from your phone (with your own domain, and how to stop using it at Cloudflare) and build it with several computers: who links the other computers (the repository's owner with a one-time code, or an organization with the Admin role), the same branch, what each computer is good at, what to do when one waits.
- **The first steps go further**: three cards lead to GitHub, the phone and several computers, and "How it works" links on the Overview, the Remote page and the GitHub block open the right tutorial.
- **Clearer texts**: linking a repository you do not administer explains the two ways to do it anyway; the shared workshop no longer says "only one pilot at a time" and points to several computers; the Overview says exactly what to do on the other computer.
- **Chat on a phone, readable**: the conversation takes the whole page instead of a small box, the field to write in stays at the bottom of the screen and grows with the text, and Enter makes a new line (the Send button sends).
- **The 6-digit pairing code no longer flickers**: with the mouse on the right of its box, the code showed, the box got narrower, the mouse left it and the code hid again. The box now keeps its size.

## Nouveautés de la 2.34.0

- **Une page Guide, toujours dans le menu** : des tutoriels pas à pas pour démarrer un projet, le lier à GitHub, le suivre depuis votre téléphone (avec votre propre domaine, et comment ne plus l'utiliser chez Cloudflare) et le construire avec plusieurs ordinateurs : qui lie les autres ordinateurs (le propriétaire du dépôt avec un code à usage unique, ou une organisation avec le rôle Admin), la même branche, ce que chaque ordinateur sait bien faire, que faire quand l'un d'eux attend.
- **Des premiers pas qui vont plus loin** : trois cartes mènent à GitHub, au téléphone et à plusieurs ordinateurs, et des liens « Comment ça marche » dans le Suivi, la page À distance et l'encadré GitHub ouvrent le bon tutoriel.
- **Des textes plus clairs** : lier un dépôt dont vous n'êtes pas administrateur explique les deux façons de le faire quand même ; l'atelier partagé ne dit plus « un seul pilote à la fois » et renvoie vers plusieurs ordinateurs ; le Suivi dit exactement quoi faire sur l'autre ordinateur.
- **Discuter sur un téléphone, enfin lisible** : la conversation occupe toute la page au lieu d'une petite boîte, le champ pour écrire reste en bas de l'écran et grandit avec le texte, et Entrée fait un retour à la ligne (le bouton Envoyer envoie).
- **Le code d'appairage à 6 chiffres ne clignote plus** : avec la souris à droite de son encadré, le code s'affichait, l'encadré rétrécissait, la souris en sortait et le code se cachait de nouveau. L'encadré garde maintenant sa taille.
