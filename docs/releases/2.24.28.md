## What's new in 2.24.28

- **Native Windows, Go pilot: no more console windows flashing on the screen.** Athanor.exe has no console of its own, and the pilot runs under a Git Bash whose console has no window: every program the Go pilot started (git above all, several times per cycle, and the tools) opened a console window of its own, which flashed and closed. Athanor.exe's sub-commands now share the console of the program that started them, so their programs open no window. If there is none to share, the pilot's log says so.

---

## Nouveautés de la 2.24.28

- **Windows natif, pilote Go : plus de fenêtres de console qui clignotent à l'écran.** Athanor.exe n'a pas de console à lui, et le pilote tourne sous un Git Bash dont la console n'a pas de fenêtre : chaque programme lancé par le pilote Go (git surtout, plusieurs fois par cycle, et les outils) ouvrait sa propre fenêtre de console, qui apparaissait puis se refermait. Les sous-commandes d'Athanor.exe partagent désormais la console du programme qui les a lancées, et leurs programmes n'ouvrent plus de fenêtre. S'il n'y en a aucune à partager, le journal du pilote le signale.
