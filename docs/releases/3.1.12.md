## What's new in 3.1.12

- **Start starts the project you clicked**: Start checks GitHub first, which can take a few seconds. Choosing another project meanwhile no longer starts that other project instead.
- **Every running project followed live**: on Projects, Home and Missions, what each running project's lead is doing now moves on by itself, not only for the selected project. Before, the line of another running project stayed frozen until that project was opened.
- **More pages follow live**: Requests, Deployment, a mission's page and Manage now update by themselves when their data changes (a request taken, a milestone done, a deployment, the pilot stopped), without leaving the page and coming back. A field you typed in and have not saved yet is never wiped.

---

## Nouveautés de la 3.1.12

- **Démarrer lance le projet sur lequel vous avez cliqué** : Démarrer vérifie d'abord GitHub, ce qui peut prendre quelques secondes. Choisir un autre projet pendant ce temps ne lance plus cet autre projet à sa place.
- **Chaque projet en marche suivi en direct** : sur Projets, l'Accueil et Missions, ce que fait le chef de projet de chaque projet en marche avance tout seul, et plus seulement pour le projet sélectionné. Avant, la ligne d'un autre projet en marche restait figée jusqu'à ce qu'on ouvre ce projet.
- **Plus de pages suivies en direct** : Demandes, Déploiement, la page d'une mission et Gérer se mettent à jour seules quand leurs données changent (une demande prise, un jalon fini, un déploiement, le pilote arrêté), sans quitter la page pour y revenir. Un champ que vous avez rempli sans l'enregistrer n'est jamais effacé.
