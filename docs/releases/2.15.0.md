## What's new in 2.15.0

- **Roblox Studio in the verified catalog**: Claude drives the open Roblox Studio (scripts, instances, play tests, assets) through Studio's built-in MCP server. Install it from *Skills & MCP*, switch it on for the project, and in Studio turn on *Enable Studio as MCP server* (*Assistant > … > Manage MCP Servers*). The path of Studio's launcher is a setting of the server (`%LOCALAPPDATA%\Roblox\mcp.bat` by default). Experimental.
- **The pilot opens Roblox Studio** before each cycle on the project's first `.rbxl`/`.rbxlx` place, on Claude's desktop when that option is on, unless a Studio is already open (yours included: Claude then works in it). Claude can open it too, with the new `roblox-studio` gateway.
- **Windows programs as MCP servers**: a server that is a Windows program (a `.exe`, a `.bat`, a `C:\` path, `cmd.exe /c …` as Claude Desktop gives it) now runs on Windows, through WSL. Athanor recognizes it when you paste its configuration and asks you to confirm with the new *Windows program* option: a server never leaves the cage on its command alone. It cannot be caged from WSL: it runs with your rights, receives only its own variables (never the Claude token), and Claude only sees its tools. When the session ends, the program and everything it started are stopped. With *Claude's desktop* on, it opens there.
- The *Test* button stops a server the way Claude Code does (end of input, then a stop signal), so that a Windows program is never left running.

## Nouveautés de la 2.15.0

- **Roblox Studio dans le catalogue vérifié** : Claude pilote Roblox Studio ouvert (scripts, instances, tests en jeu, ressources) via le serveur MCP intégré à Studio. Installez-le depuis *Skills & MCP*, activez-le pour le projet, et dans Studio activez *Enable Studio as MCP server* (*Assistant > … > Manage MCP Servers*). Le chemin du lanceur de Studio est un réglage du serveur (`%LOCALAPPDATA%\Roblox\mcp.bat` par défaut). Expérimental.
- **Le pilote ouvre Roblox Studio** avant chaque cycle sur la première place `.rbxl`/`.rbxlx` du projet, sur le bureau de Claude si cette option est activée, sauf si un Studio est déjà ouvert (le vôtre compris : Claude y travaille alors). Claude peut aussi l'ouvrir, avec la nouvelle passerelle `roblox-studio`.
- **Des programmes Windows comme serveurs MCP** : un serveur qui est un programme Windows (un `.exe`, un `.bat`, un chemin `C:\`, `cmd.exe /c …` comme le donne Claude Desktop) tourne désormais sous Windows, via WSL. Athanor le reconnaît quand vous collez sa configuration et vous demande de confirmer avec la nouvelle option *Programme Windows* : un serveur ne sort jamais de la cage sur sa seule commande. Il ne peut pas être mis en cage depuis WSL : il tourne avec vos droits, ne reçoit que ses propres variables (jamais le jeton Claude), et Claude ne voit que ses outils. À la fin de la session, le programme et tout ce qu'il a lancé sont arrêtés. Avec le *bureau de Claude* activé, il s'y ouvre.
- Le bouton *Tester* arrête un serveur comme le fait Claude Code (fin de l'entrée, puis un signal d'arrêt), pour qu'un programme Windows ne reste jamais lancé.
