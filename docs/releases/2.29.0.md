## What's new in 2.29.0

- **Clearer downloads**: one file per system, named after it: `Athanor-Windows-x64.exe` (an ARM PC: `Athanor-Windows-ARM64.exe`), `Athanor-macOS.zip`, `Athanor-Linux-x64` (an ARM PC: `Athanor-Linux-ARM64`). The release page starts with which one to take.
- **On the Mac, the update comes from the zip** of Athanor.app: no separate Mac file any more.
- This version still publishes the previous names too (`Athanor.exe`, `athanor-linux`, `athanor-macos`…), so that every Athanor already installed finds it from *Update now*. They go with the next version.

## Nouveautés de la 2.29.0

- **Des téléchargements plus clairs** : un fichier par système, à son nom : `Athanor-Windows-x64.exe` (un PC ARM : `Athanor-Windows-ARM64.exe`), `Athanor-macOS.zip`, `Athanor-Linux-x64` (un PC ARM : `Athanor-Linux-ARM64`). La page de la version commence par celui à prendre.
- **Sur le Mac, la mise à jour vient du zip** d'Athanor.app : plus de fichier Mac à part.
- Cette version publie encore les anciens noms (`Athanor.exe`, `athanor-linux`, `athanor-macos`…), pour que tout Athanor déjà installé la trouve depuis *Mettre à jour maintenant*. Ils partent avec la version suivante.
