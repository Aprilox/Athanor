## What's new in 2.38.0

- **This computer connected to GitHub, once**: *Settings › Options › GitHub › Connect to GitHub* signs in a single time and puts a key "Athanor (this computer)" on your GitHub account, kept by Athanor. From then on, *Use one of my repositories* and *Join a project* link at once, with no window and no new sign-in, for any repository your account can push to: your own, or one you are a collaborator of. Only creating a new repository still opens a sign-in.
- **Checked at once, and said plainly**: right after you choose the repository, Athanor checks that your account can read it and push to it. When it cannot, it says why: not found (check the name, or ask to be added as a collaborator), read access only (ask for write access), or GitHub unreachable. A repository with GitHub Actions workflows is confirmed first.
- **Projects already linked** keep their key; *Use my GitHub connection* moves one to the connection. *Disconnect* removes the key from this computer.
- A collaborator who links a project without the connection is offered it, instead of a key for that project alone (2.37).
- **Commits without Claude as co-author by default**: *Commit without Claude as co-author* is now ticked unless you chose otherwise for a project (a choice saved before stays as it is).

## Nouveautés de la 2.38.0

- **Cet ordinateur connecté à GitHub, une fois pour toutes** : *Réglages › Options › GitHub › Se connecter à GitHub* se connecte une seule fois et met une clé « Athanor (cet ordinateur) » sur votre compte GitHub, gardée par Athanor. Ensuite, *Utiliser un de mes dépôts* et *Rejoindre un projet* lient aussitôt, sans fenêtre et sans nouvelle connexion, pour tout dépôt que votre compte peut modifier : le vôtre, ou un dont vous êtes contributeur. Seule la création d'un nouveau dépôt ouvre encore une connexion.
- **Vérifié tout de suite, et dit clairement** : juste après le choix du dépôt, Athanor vérifie que votre compte peut le lire et y envoyer. Sinon, il dit pourquoi : introuvable (vérifiez le nom, ou demandez à être ajouté comme contributeur), lecture seule (demandez l'accès en écriture), ou GitHub injoignable. Un dépôt avec des workflows GitHub Actions est d'abord confirmé.
- **Les projets déjà liés** gardent leur clé ; *Utiliser ma connexion GitHub* en fait passer un à la connexion. *Se déconnecter* retire la clé de cet ordinateur.
- Un contributeur qui lie un projet sans la connexion se la voit proposer, au lieu d'une clé pour ce seul projet (2.37).
- **Commits sans Claude en co-auteur par défaut** : *Commiter sans Claude en co-auteur* est maintenant coché, sauf si vous avez choisi autrement pour un projet (un choix enregistré avant reste tel quel).
