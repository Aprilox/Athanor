## What's new in 2.24.29

- **The Go pilot is now the default engine.** `PILOT_ENGINE=go` (Settings) is the default; the bash pilot stays as a backup (`PILOT_ENGINE=bash`, shown as *bash (backup)*), and the bash pilot still carries on by itself if the Go pilot hits an internal error.
- **Athanor no longer needs Python.** Every helper the pilot used to run in Python (guard, settings, relay, costs, quota, team, skills & MCP, tasks for you, bridge, Roblox sync…) runs in Athanor's executable. The `system/*.py` files are gone (kept only as test references in `app/testdata/oracles`). If the executable is missing or too old for the kit, the pilot says so and stops, with what to do: *Setup & health → Rebuild Athanor*.
- **Installing and configuring in Go.** `commands/install.sh` and `commands/configure.sh` are now short wrappers around `athanor installer` and `athanor configurer`: same questions, same `.env`, same packages (checked side by side against the former scripts). `system/detect-tools.sh` is replaced by `athanor detecter`; `ecran.sh`, `mcp-jail.sh` and `windows-mcp.sh` call the executable.
- **macOS (first version, experimental).** Installation with Homebrew in a Terminal window; Claude works in macOS' own sandbox (Seatbelt) and only writes in the project; the PC tools are detected (Xcode, Blender, Godot, Unreal Engine, Roblox Studio, Android SDK…); the application opens in its own window, keeps the Mac awake during a run (caffeinate) and can start at login. The releases now include Mac executables (Apple Silicon and Intel). Not yet tried on a real Mac: tell us what goes wrong.
- Kept for now: the Windows installers (PowerShell), and in native Windows the GitHub linking and the gateways to the PC tools (bash).

## Nouveautés de la 2.24.29

- **Le pilote Go devient le moteur par défaut.** `PILOT_ENGINE=go` (Réglages) est la valeur par défaut ; le pilote bash reste en secours (`PILOT_ENGINE=bash`, affiché *bash (secours)*), et il prend toujours le relais tout seul si le pilote Go rencontre une erreur interne.
- **Athanor n'a plus besoin de Python.** Tous les assistants que le pilote lançait en Python (garde, réglages, relais, coûts, quota, équipe, compétences et MCP, tâches pour vous, pont, synchro Roblox…) tournent dans l'exécutable d'Athanor. Les fichiers `system/*.py` disparaissent (gardés seulement comme références de test dans `app/testdata/oracles`). Si l'exécutable manque ou est trop ancien pour le kit, le pilote le dit et s'arrête, avec la marche à suivre : *Installation & santé → Recompiler Athanor*.
- **Installation et configuration en Go.** `commands/install.sh` et `commands/configure.sh` ne sont plus que des raccourcis vers `athanor installer` et `athanor configurer` : mêmes questions, même `.env`, mêmes paquets (vérifiés côte à côte avec les anciens scripts). `system/detect-tools.sh` est remplacé par `athanor detecter` ; `ecran.sh`, `mcp-jail.sh` et `windows-mcp.sh` appellent l'exécutable.
- **macOS (première version, expérimentale).** Installation avec Homebrew dans une fenêtre Terminal ; Claude travaille dans la cage propre à macOS (Seatbelt) et n'écrit que dans le projet ; les outils du PC sont détectés (Xcode, Blender, Godot, Unreal Engine, Roblox Studio, Android SDK…) ; l'application s'ouvre dans sa propre fenêtre, garde le Mac éveillé pendant une exécution (caffeinate) et peut démarrer à l'ouverture de session. Les versions publiées contiennent désormais les exécutables Mac (Apple Silicon et Intel). Pas encore essayé sur un vrai Mac : dites-nous ce qui coince.
- Gardés pour l'instant : les installateurs Windows (PowerShell) et, en Windows natif, la liaison GitHub et les passerelles vers les outils du PC (bash).
