## What's new in 2.40.2

- **Several computers, the second one gets the request and the plan**: switching on *Work with other computers* (or ticking *Share the workshop (.athanor/) on GitHub*) now commits the workshop at once, alone (the request, the plan, the log; never the code being written nor the pilot's state), and pushes it. Before, it waited for Claude's next commit: a computer that joined meanwhile got a project with no request and could not start.
- A computer of the team with no request yet starts anyway: while it waits, its pilot brings in the other computers' work every minute, and the request comes with it (before, it waited for a request typed on that computer).
- *Push now*, with the workshop shared, also takes what changed in it since Claude's last commit.

## Nouveautés de la 2.40.2

- **Plusieurs ordinateurs, le deuxième reçoit la demande et le plan** : activer *Travailler avec d'autres ordinateurs* (ou cocher *Partager l'atelier (.athanor/) sur GitHub*) commite maintenant l'atelier aussitôt, seul (la demande, le plan, le journal de bord ; jamais le code en cours d'écriture ni l'état du pilote), et l'envoie. Avant, il attendait le prochain commit de Claude : un ordinateur qui rejoignait entre-temps recevait un projet sans demande et ne pouvait pas démarrer.
- Un ordinateur de l'équipe qui n'a pas encore de demande démarre quand même : pendant qu'il attend, son pilote ramène le travail des autres ordinateurs chaque minute, et la demande arrive avec (avant, il attendait une demande tapée sur cet ordinateur).
- *Envoyer maintenant*, avec l'atelier partagé, prend aussi ce qui y a changé depuis le dernier commit de Claude.
