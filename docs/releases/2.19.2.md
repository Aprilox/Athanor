## What's new in 2.19.2

- **Native Windows mode: programs installed while Athanor runs are found at once.** The scripts get the PATH as Windows has it now, not the one Athanor started with: jq, Python or Git installed by *Install everything* no longer need a restart of Athanor. jq is also looked for where winget puts it.

---

## Nouveautés de la 2.19.2

- **Mode Windows natif : les programmes installés pendant qu'Athanor tourne sont trouvés tout de suite.** Les scripts reçoivent le PATH tel que Windows l'a maintenant, pas celui du démarrage d'Athanor : jq, Python ou Git installés par *Tout installer* ne demandent plus de relancer Athanor. jq est aussi cherché là où winget le met.
