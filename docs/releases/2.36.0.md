## What's new in 2.36.0

- **Join a project in one screen**: *Join a project* in the project picker. The repository, its branch, a new folder: one window signs in to GitHub, links the project and brings the team's work in (its request, its plan, its log). No more new project, link, then switch.
- **Notifications on the phone**: on a paired phone, *Remote → This device → Notifications on this device*. A notification even with Athanor closed on the phone, when Claude needs you, when a milestone is done, when a project is delivered and when a computer of a team is stuck; a tap opens the right page. Encrypted for that device alone (Web Push). On an iPhone or iPad, add Athanor to the Home Screen first.
- **Levels of power**: a computer's word may carry a level (`gpu:3`, `gpu:1`). A milestone that needs a lot (`Needs: gpu:3.`) goes to the most capable computer; the others take the lighter ones at the same time.
- **Notes between the computers**: their Claude leave each other notes (an interface that changed, a trap to avoid) in `.athanor/TEAM_NOTES.md`; each one reads the last ones before it starts, and the Overview shows them.
- **Work never lost**: a computer sends its unfinished work to GitHub every 10 minutes and when its pilot stops, on a branch of its own. If it goes away, the computer that takes the milestone next goes on from there; when it comes back, its own copy is kept aside, never mixed with the team's.
- **Browse… for the project's folder**: *New project*, *Join a project* and *Manage* have a *Browse…* button that opens the system's own folder dialog (Windows', macOS', or zenity's and kdialog's on Linux); OK fills the field. From a phone, or without a system dialog, Athanor's own folder picker opens instead.

## Nouveautés de la 2.36.0

- **Rejoindre un projet en un écran** : *Rejoindre un projet* dans le sélecteur de projets. Le dépôt, sa branche, un nouveau dossier : une fenêtre se connecte à GitHub, lie le projet et fait venir le travail de l'équipe (sa demande, son plan, son journal de bord). Plus besoin de nouveau projet, puis lier, puis interrupteur.
- **Les notifications sur le téléphone** : sur un téléphone appairé, *À distance → Cet appareil → Notifications sur cet appareil*. Une notification même Athanor fermé sur le téléphone, quand Claude a besoin de vous, quand un jalon est fini, quand un projet est livré et quand un ordinateur d'une équipe bloque ; un appui ouvre la bonne page. Chiffrée pour cet appareil seul (Web Push). Sur un iPhone ou un iPad, ajoutez d'abord Athanor à l'écran d'accueil.
- **Des niveaux de puissance** : le mot d'un ordinateur peut porter un niveau (`gpu:3`, `gpu:1`). Un jalon qui en demande beaucoup (`Needs: gpu:3.`) va à l'ordinateur le plus puissant ; les autres prennent les plus légers en même temps.
- **Des notes entre les ordinateurs** : leurs Claude se laissent des notes (une interface qui a changé, un piège à éviter) dans `.athanor/TEAM_NOTES.md` ; chacun lit les dernières avant de commencer, et le Suivi les montre.
- **Un travail jamais perdu** : un ordinateur envoie son travail inachevé sur GitHub toutes les 10 minutes et quand son pilote s'arrête, sur une branche à lui. S'il s'en va, l'ordinateur qui prend ensuite le jalon repart de là ; quand il revient, sa propre copie est gardée de côté, jamais mélangée à celle de l'équipe.
- **Parcourir… pour le dossier du projet** : *Nouveau projet*, *Rejoindre un projet* et *Gérer* ont un bouton *Parcourir…* qui ouvre la fenêtre de choix de dossier du système (celle de Windows, de macOS, ou de zenity et kdialog sous Linux) ; OK remplit le champ. Depuis un téléphone, ou sans fenêtre du système, c'est le sélecteur de dossier d'Athanor qui s'ouvre.
