## What's new in 2.18.0

- **Workers that see each other.** In parallel mode, the pilot writes a team board, `.athanor/BOARD.md`, into every worker's workshop every few seconds: who is doing what, the files each one holds, what is done, who waits. A worker that needs a file outside its sheet reserves it first (`.athanor/RESERVE`): the pilot grants it, or refuses it when another worker holds it, and says so on the board. No new worker starts on a reserved file.
- **A relay when the context is full.** Every session keeps `.athanor/HANDOFF.md`, where it is in 10 lines. Past `RELAY_CONTEXT_K` thousand tokens of context (150 by default, 0 = never), the pilot stops it between two steps (10 min later at most) and starts a fresh session on the same milestone, with that file, the last actions and the last messages of the previous one. Turns get cheap again and no automatic compaction blurs the thread. A worker is relayed the same way, on its branch, in the same cycle.
- **Work done inside a program is saved.** The lead's instructions now say to save into the project, before ticking a milestone, whatever was done inside a program driven through an MCP server (an editor, an engine, a design tool). If a milestone used an MCP server and its commit changed no file, the pilot has the lead save that work first on the next cycle (`.athanor/SAVE_CHECK`). The catalogue's Roblox Studio and Unreal servers say how to save in them, and that line comes with the server.

## Nouveautés de la 2.18.0

- **Des ouvriers qui se voient.** En mode parallèle, le pilote écrit toutes les quelques secondes un tableau d'équipe, `.athanor/BOARD.md`, dans l'atelier de chaque ouvrier : qui fait quoi, les fichiers que chacun tient, ce qui est fait, qui attend. Un ouvrier qui a besoin d'un fichier hors de sa fiche le réserve d'abord (`.athanor/RESERVE`) : le pilote l'accorde, ou le refuse si un autre ouvrier le tient, et l'écrit sur le tableau. Aucun nouvel ouvrier ne démarre sur un fichier réservé.
- **Un passage de relais quand le contexte est plein.** Chaque session tient `.athanor/HANDOFF.md`, où elle en est en 10 lignes. Au-delà de `RELAY_CONTEXT_K` milliers de tokens de contexte (150 par défaut, 0 = jamais), le pilote l'arrête entre deux étapes (10 min plus tard au plus) et lance une nouvelle session sur le même jalon, avec ce fichier, les dernières actions et les derniers messages de la précédente. Les tours redeviennent bon marché et aucune compaction automatique ne brouille le fil. Un ouvrier est relayé de la même façon, sur sa branche, dans le même cycle.
- **Le travail fait dans un programme est enregistré.** Les consignes du chef disent maintenant d'enregistrer dans le projet, avant de cocher un jalon, ce qui a été fait dans un programme piloté par un serveur MCP (un éditeur, un moteur, un logiciel de création). Si un jalon a utilisé un serveur MCP et que son commit n'a changé aucun fichier, le pilote fait d'abord enregistrer ce travail par le chef au cycle suivant (`.athanor/SAVE_CHECK`). Les serveurs Roblox Studio et Unreal du catalogue disent comment enregistrer chez eux, et cette ligne accompagne le serveur.
