## What's new in 2.12.0

- **Plugins**: a new tab on the *Skills & MCP* page lists every plugin of Claude Code's official marketplace (more than 300: Shopify, Stripe, Notion, Figma, Sentry, databases…), searchable and filtered by category. Add any other marketplace with its GitHub repository.
- **Installed once, switched on per project**: one click installs a plugin in Athanor; a switch turns it on for the projects that need it, for the lead and the parallel workers, from the next cycle. *Update* fetches its latest version.
- **Safe by design**: a plugin is taken apart. Its skills, commands and sub-agents are loaded read-only; its MCP servers join the MCP library (local ones run in the cage); its hooks and LSP servers are left out, because they would run outside Claude's sandbox.
- **Sign in once**: a remote MCP server that asks you to sign in (OAuth) gets a *Sign in* button: a window opens, you sign in once, and it is valid for every project. The keys a plugin needs are entered once, for the whole application.

## Nouveautés de la 2.12.0

- **Plugins** : un nouvel onglet de la page *Skills & MCP* liste tous les plugins du catalogue officiel de Claude Code (plus de 300 : Shopify, Stripe, Notion, Figma, Sentry, bases de données…), avec recherche et filtre par catégorie. Ajoutez n'importe quel autre catalogue avec son dépôt GitHub.
- **Installés une fois, activés par projet** : un clic installe un plugin dans Athanor ; un interrupteur l'active pour les projets qui en ont besoin, pour le chef et les ouvriers en parallèle, dès le cycle suivant. *Mettre à jour* récupère sa dernière version.
- **Sûr par construction** : un plugin est démonté. Ses skills, ses commandes et ses sous-agents sont chargés en lecture seule ; ses serveurs MCP rejoignent la bibliothèque MCP (les locaux tournent dans la cage) ; ses hooks et ses serveurs LSP sont écartés, car ils tourneraient hors de la barrière de Claude.
- **Une seule connexion** : un serveur MCP distant qui demande de se connecter (OAuth) a un bouton *Se connecter* : une fenêtre s'ouvre, vous vous connectez une fois, et c'est valable pour tous les projets. Les clés dont un plugin a besoin se saisissent une fois, pour toute l'application.
