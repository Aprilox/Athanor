## What's new in 3.1.6

- **Each project's own tools stay with it.** What only one project uses (its test server or world, a tool built or patched for it, an old version it pins) now goes into that project's `.athanor/tools/`, never shared on GitHub and removed with the project, instead of Athanor's `tools/`. What projects can share stays shared: Gradle's downloads now always go to `tools/gradle` (`GRADLE_USER_HOME`), whatever the project.
- **A recorded way to install a tool is a hint, not the latest word**: Claude takes the current version (unless the project pins one) and replaces a line of `SOLUTIONS.md` or `INSTALLS.md` when it meets a better way.
- **`logs/` empties itself**: the folders of the projects removed from the list and of the old team tunnels go after 30 days without activity, and the repair sessions' log turns over past 4 MB.
- **The pilot's link check works again**: the symbolic links placed in `.athanor/` are removed at each cycle as intended (it looked into an empty `.athanor/.athanor` folder, now removed).
- **The documentation's links**: the *Security* page GitHub shows on the repository's *Security* tab no longer leads to missing pages (*Français*, *Athanor Hub README*); every guide starts with the same line back to the README and to its other language, and the French *Servers* guide links the French *Missions*.

## Nouveautés de la 3.1.6

- **Les outils propres à un projet restent avec lui.** Ce qui ne sert qu'à un projet (son serveur ou son monde de test, un outil fait ou modifié pour lui, une ancienne version qu'il impose) va maintenant dans le `.athanor/tools/` de ce projet, jamais partagé sur GitHub et supprimé avec lui, au lieu du `tools/` d'Athanor. Ce que les projets peuvent partager le reste : les téléchargements de Gradle vont maintenant toujours dans `tools/gradle` (`GRADLE_USER_HOME`), quel que soit le projet.
- **Une façon d'installer un outil déjà notée est une piste, pas le dernier mot** : Claude prend la version actuelle (sauf si le projet en impose une) et remplace une ligne de `SOLUTIONS.md` ou d'`INSTALLS.md` quand il trouve mieux.
- **`logs/` se vide tout seul** : les dossiers des projets retirés de la liste et des anciens tunnels d'équipe partent après 30 jours sans activité, et le journal des sessions de réparation tourne au-delà de 4 Mo.
- **La vérification des liens du pilote fonctionne de nouveau** : les liens symboliques placés dans `.athanor/` sont retirés à chaque cycle comme prévu (elle regardait un dossier `.athanor/.athanor` vide, maintenant supprimé).
- **Les liens de la documentation** : la page *Sécurité* que GitHub affiche dans l'onglet *Security* du dépôt ne mène plus à des pages introuvables (*Français*, *README d'Athanor Hub*) ; chaque guide commence par la même ligne vers le README et vers son autre langue, et le guide *Serveurs* en français renvoie aux *Missions* en français.
