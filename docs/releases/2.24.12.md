## What's new in 2.24.12

Move to Go, step 1.5: the pilot's two services.

- **`athanor pont`** replaces `bridge.py`: the bridge that runs, outside Claude's sandbox, the PC tools Claude asks for (Docker's `tool`, Unreal, Blender, Roblox Studio, Windows programs…), with their output streamed back live. The same rules: only the listed gateways, only from the project or `tools/`, never through a link, stopped with the pilot.
- **`athanor roblox-sync`** replaces `roblox-sync.py`: the scripts of a Rojo project reach the open Roblox Studio without restarting it (`.athanor/studio/SYNC.luau`), the same tree, the same answers, the same `SYNC.luau`.
- As before, the pilot uses them only when the kit's executable runs here and knows them; otherwise, or with `ATHANOR_OUTILS=python`, the Python scripts.
- **Checked against the scripts**: the bridge with allowed and refused gateways, folders inside and outside, settings passed or not, a gateway killed, one cancelled, requests being written, wrong names and links; the Studio sync with every kind of Rojo script and folder, ignored paths, legacy and new scripts, a broken or missing project file, a model changed between two requests, a wrong key, and the stop with the pilot. In the pilot's test bench, a gateway run through the bridge gives the same output and code with both, and no bridge outlives its pilot.

## Nouveautés de la 2.24.12

Passage à Go, étape 1.5 : les deux services du pilote.

- **`athanor pont`** remplace `bridge.py` : le pont qui lance, hors du bac à sable de Claude, les outils du PC que Claude demande (`tool` pour Docker, Unreal, Blender, Roblox Studio, programmes Windows…), leur sortie renvoyée en direct. Mêmes règles : seulement les passerelles prévues, seulement depuis le projet ou `tools/`, jamais à travers un lien, arrêté avec le pilote.
- **`athanor roblox-sync`** remplace `roblox-sync.py` : les scripts d'un projet Rojo arrivent dans Roblox Studio ouvert sans le relancer (`.athanor/studio/SYNC.luau`), même arbre, mêmes réponses, même `SYNC.luau`.
- Comme avant, le pilote ne s'en sert que si l'exécutable du kit tourne ici et les connaît ; sinon, ou avec `ATHANOR_OUTILS=python`, les scripts Python.
- **Vérifiés contre les scripts** : le pont avec des passerelles permises et refusées, des dossiers dedans et dehors, des réglages transmis ou non, une passerelle tuée, une annulée, des demandes en cours d'écriture, des noms invalides et des liens ; la synchronisation Studio avec tous les types de scripts et dossiers Rojo, chemins ignorés, scripts anciens et nouveaux, un fichier de projet cassé ou absent, un modèle changé entre deux demandes, une mauvaise clé, et l'arrêt avec le pilote. Dans le banc d'essai du pilote, une passerelle passée par le pont donne la même sortie et le même code avec les deux, et aucun pont ne survit à son pilote.
