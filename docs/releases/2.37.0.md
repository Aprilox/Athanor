## What's new in 2.37.0

- **Two people, in turns, on one repository**: without an organization and without *Work with other computers*. The owner adds the other as a collaborator on GitHub; each one links the project on their own computer.
  - **A collaborator can link**: GitHub only lets a repository's administrator give it a key of its own, so linking used to fail for a collaborator. Athanor now offers to put the key on the collaborator's own GitHub account instead: one more confirmation (`yes`) and one more authorization in the browser. That key opens what the account can push to, stays out of Claude's reach, and can be removed any time in GitHub's *Settings › SSH and GPG keys*. A collaborator with read access only is told to ask for write access.
  - **Get GitHub's work** (*Manage › GitHub*): brings in what the other pushed, as `git pull` would (a fast-forward, or a merge). Never over changes not committed; a real conflict is undone at once and left to Claude, who merges it at the start of the next cycle, keeping both sides.
  - **Start checks it**: when GitHub has commits the folder does not, Athanor says how many, the last one and who pushed it, and asks: bring them in then start, start from here, or cancel.
- The *Share the workshop* switch of the GitHub block now shows its real state (it always showed unticked).

## Nouveautés de la 2.37.0

- **À deux, chacun son tour, sur un même dépôt** : sans organisation et sans *Travailler avec d'autres ordinateurs*. Le propriétaire ajoute l'autre comme contributeur sur GitHub ; chacun lie le projet sur son ordinateur.
  - **Un contributeur peut lier le projet** : GitHub ne laisse que l'administrateur d'un dépôt lui donner une clé à lui, donc la liaison échouait pour un contributeur. Athanor propose maintenant de mettre la clé sur le compte GitHub du contributeur : une confirmation de plus (`yes`) et une autorisation de plus dans le navigateur. Cette clé ouvre ce que le compte peut modifier, reste hors de portée de Claude, et se retire quand on veut dans *Settings › SSH and GPG keys* de GitHub. Un contributeur en lecture seule est invité à demander l'accès en écriture.
  - **Récupérer le travail de GitHub** (*Gérer › GitHub*) : ramène ce que l'autre a poussé, comme `git pull` (une avance rapide ou une fusion). Jamais par-dessus des modifications non commitées ; un vrai conflit est aussitôt annulé et laissé à Claude, qui le fusionne au début du cycle suivant en gardant les deux côtés.
  - **Démarrer le vérifie** : si GitHub a des commits que le dossier n'a pas, Athanor dit combien, le dernier et qui l'a poussé, et demande : les ramener puis démarrer, démarrer d'ici, ou annuler.
- L'interrupteur *Partager l'atelier* de l'encadré GitHub montre maintenant son vrai état (il paraissait toujours décoché).
