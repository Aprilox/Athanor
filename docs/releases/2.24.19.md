## What's new in 2.24.19

The gateways move to Go (the move of Athanor to Go, step 2.3).

- **`athanor passerelle`**: the PC side of the gateways Claude calls (`blender`, `roblox-studio`, `unreal-editor`, `unreal-cmd`, `unreal-uat`, `pc-exec`, `install-windows`, `windows-var`, `adb`, `tool`) is now done by Athanor's executable in WSL, with the same checks (a program of the tools or of the project only, a file inside the project), the same messages and exit codes, Claude's desktop, the administrator task and the Rojo build of Roblox projects. They keep their names: Claude calls them exactly as before.
- Inside Claude's sandbox, a gateway hands its command to the bridge without Python (`jq`; Python only if `jq` is missing).
- Native Windows keeps the scripts; `ATHANOR_OUTILS=python` still forces them everywhere.
- **Checked**: 60 cases run with the scripts and with Go on a fake Windows (opening Blender, Studio and Unreal, already open, refused files, exit codes, Claude's desktop, programs needing administrator rights with and without the task, winget installs and their log, Rojo builds that fail, a locked session): the same outputs, codes and calls to every Windows program.

## Nouveautés de la 2.24.19

Les passerelles passent en Go (passage d'Athanor en Go, étape 2.3).

- **`athanor passerelle`** : le côté PC des passerelles que Claude appelle (`blender`, `roblox-studio`, `unreal-editor`, `unreal-cmd`, `unreal-uat`, `pc-exec`, `install-windows`, `windows-var`, `adb`, `tool`) est maintenant fait par l'exécutable d'Athanor sous WSL, avec les mêmes contrôles (un programme des outils ou du projet seulement, un fichier dans le projet), les mêmes messages et codes de sortie, le bureau de Claude, la tâche administrateur et la construction Rojo des projets Roblox. Elles gardent leur nom : Claude les appelle exactement comme avant.
- Dans le bac à sable de Claude, une passerelle confie sa commande au pont sans Python (`jq` ; Python seulement si `jq` manque).
- Windows natif garde les scripts ; `ATHANOR_OUTILS=python` les force toujours partout.
- **Vérifié** : 60 cas lancés avec les scripts et avec Go sur un faux Windows (ouverture de Blender, Studio et Unreal, déjà ouverts, fichiers refusés, codes de sortie, bureau de Claude, programmes qui demandent les droits administrateur avec et sans la tâche, installations winget et leur journal, constructions Rojo en échec, session verrouillée) : mêmes sorties, mêmes codes et mêmes appels à chaque programme Windows.
