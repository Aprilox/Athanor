## What's new in 2.42.0

- **Remote in the terminal** (`athanor tui`, page **0**): switch remote access on or off (**o**), the pairing QR code drawn right in the terminal with its link, the 6 digits shown on **v** for 10 seconds, the trusted devices renamed (**r**) or removed (**d**). A computer reached through SSH, or without a screen, now pairs a phone and is driven from it, from anywhere.
- **Releases only once every test passes**: a version tag first runs the whole CI on its commit (tests on Windows, Linux and macOS, the single executable, every build target). If any check fails, nothing is published: the tag and the release are removed, so Athanor's updates never offer a version whose tests failed.

## Nouveautés de la 2.42.0

- **À distance dans le terminal** (`athanor tui`, page **0**) : activer ou couper l'accès à distance (**o**), le QR code d'appairage dessiné directement dans le terminal avec son lien, les 6 chiffres affichés sur **v** pendant 10 secondes, les appareils de confiance renommés (**r**) ou retirés (**d**). Un ordinateur joint en SSH, ou sans écran, appaire maintenant un téléphone et se pilote depuis lui, de n'importe où.
- **Une version n'est publiée que si tous les tests passent** : un tag de version lance d'abord toute la CI sur son commit (tests sous Windows, Linux et macOS, exécutable unique, toutes les cibles). Si une seule vérification échoue, rien n'est publié : le tag et la version sont supprimés, et les mises à jour d'Athanor ne proposent jamais une version dont les tests ont échoué.
