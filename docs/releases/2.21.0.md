## What's new in 2.21.0

- **Roblox Studio stays open, and the code reaches it live.** In a Rojo project (a `default.project.json`), Claude no longer kills and restarts Studio to see each change of code (up to 3 minutes of waiting per cycle):
  - the pilot builds the project's place, `.athanor/studio/NAME.rbxl`, from its files and opens Studio on it; Studio then stays open from one cycle to the next;
  - after changing scripts, Claude runs `.athanor/studio/SYNC.luau` in Studio: within a second the open place's scripts are those of the project (created, updated, removed). A small server of the pilot serves them, on this PC only;
  - models, JSON and text files and the project file's own instances still need a rebuild: `roblox-studio --rebuild` closes the project's Studio (never yours), rebuilds the place and opens it again.
- **A lighter interface.**
  - The plan counts every milestone again: those the pilot archived (done long ago) were missing ("3 / 19" instead of "9 / 25"); they are folded into one line that opens them.
  - *Settings* and *Options* are one page with two tabs, *Claude* and *Options*. The pilot's settings have plain names, in groups (connection, models, how the pilot works), the models are picked in a list, and the rarely used settings are folded under *Advanced*.
  - *Manage* left the menu: it is in the project picker (*Manage this project*).
  - *Overview*: the last 5 cycles (all of them on a click), the working mode on one line, the title on one line.
- Native Windows mode: an editor Claude opens (Roblox Studio, Unreal) no longer closes at the end of the cycle; the pilot does not have to open it again.

## Nouveautés de la 2.21.0

- **Roblox Studio reste ouvert, et le code y arrive en direct.** Dans un projet Rojo (un `default.project.json`), Claude ne tue plus et ne relance plus Studio pour voir chaque changement de code (jusqu'à 3 minutes d'attente par cycle) :
  - le pilote construit la place du projet, `.athanor/studio/NOM.rbxl`, à partir de ses fichiers et ouvre Studio dessus ; Studio reste ensuite ouvert d'un cycle à l'autre ;
  - après avoir modifié des scripts, Claude exécute `.athanor/studio/SYNC.luau` dans Studio : en une seconde, les scripts de la place ouverte sont ceux du projet (créés, mis à jour, supprimés). Un petit serveur du pilote les fournit, sur ce PC seulement ;
  - les modèles, les fichiers JSON et texte et les instances du fichier de projet demandent toujours une reconstruction : `roblox-studio --rebuild` ferme le Studio du projet (jamais le vôtre), reconstruit la place et le rouvre.
- **Une interface plus légère.**
  - Le plan compte de nouveau tous les jalons : ceux que le pilote a archivés (terminés depuis longtemps) manquaient (« 3 / 19 » au lieu de « 9 / 25 ») ; ils sont repliés sur une ligne qui les ouvre.
  - *Réglages* et *Options* ne font plus qu'une page à deux onglets, *Claude* et *Options*. Les réglages du pilote ont des noms clairs, par groupes (connexion, modèles, fonctionnement du pilote), les modèles se choisissent dans une liste, et les réglages rarement utiles sont repliés sous *Avancé*.
  - *Gérer* quitte le menu : il est dans le sélecteur de projet (*Gérer ce projet*).
  - *Suivi* : les 5 derniers cycles (tous d'un clic), le mode de travail sur une ligne, le titre sur une ligne.
- Mode Windows natif : un éditeur ouvert par Claude (Roblox Studio, Unreal) ne se ferme plus à la fin du cycle ; le pilote n'a plus à le rouvrir.
