## What's new in 2.43.1

- **Roblox Studio on macOS and Linux**: the catalog's Roblox Studio server had only Windows' configuration (`cmd.exe /c %LOCALAPPDATA%\Roblox\mcp.bat`), so on a Mac its setting showed that Windows path and the server was left out. Athanor now finds Studio's MCP server on the computer: on macOS, `StudioMCP` inside `RobloxStudio.app` (`/Applications` or `~/Applications`); on Linux, Studio through [Vinegar](https://vinegarhq.org) (Flatpak or native), its `mcp.bat` started in Vinegar's own Wine (the Wine its settings name, else the one it downloads). The setting `ROBLOX_STUDIO_MCP` is empty by default (found here) and can give another path. A server already installed with Windows' configuration takes this system's on its own; a value left at the Windows default is dropped.
- **Studio opened by the pilot outside Windows**: `roblox-studio` (the pilot before each cycle, and Claude) opens Studio on the project's place with `open -a RobloxStudio` on macOS and through Vinegar on Linux, knows whether it already runs, and `--rebuild` closes the project's Studio before rebuilding the place (on macOS, Studio itself).
- On Linux, *PC tools* says when Studio is there through Vinegar.
- Linux support is experimental: tell us how it goes.

## Nouveautés de la 2.43.1

- **Roblox Studio sous macOS et Linux** : le serveur Roblox Studio du catalogue n'avait que la configuration de Windows (`cmd.exe /c %LOCALAPPDATA%\Roblox\mcp.bat`) : sur un Mac, son réglage affichait ce chemin Windows et le serveur était écarté. Athanor trouve maintenant le serveur MCP de Studio sur l'ordinateur : sous macOS, `StudioMCP` dans `RobloxStudio.app` (`/Applications` ou `~/Applications`) ; sous Linux, Studio avec [Vinegar](https://vinegarhq.org) (Flatpak ou natif), son `mcp.bat` lancé dans le Wine de Vinegar (celui de ses réglages, sinon celui qu'il télécharge). Le réglage `ROBLOX_STUDIO_MCP` est vide par défaut (trouvé ici) et peut donner un autre chemin. Un serveur déjà installé avec la configuration de Windows prend tout seul celle de ce système ; une valeur laissée au défaut de Windows est abandonnée.
- **Studio ouvert par le pilote hors de Windows** : `roblox-studio` (le pilote avant chaque cycle, et Claude) ouvre Studio sur la place du projet avec `open -a RobloxStudio` sous macOS et par Vinegar sous Linux, sait s'il tourne déjà, et `--rebuild` ferme le Studio du projet avant de reconstruire la place (sous macOS, Studio lui-même).
- Sous Linux, *Outils du PC* indique quand Studio est là via Vinegar.
- La prise en charge de Linux est expérimentale : dites-nous ce qu'il en est.
