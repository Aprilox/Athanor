## What's new in 2.32.1

- **Pairing a device now needs you in front of the computer**: scanning the QR code only opens a request. The device then asks for a 6-digit code that the *Remote* page shows only under the mouse (a tap on a touch screen), renewed every 20 seconds. A photo or a screenshot of the QR code therefore gets nobody in; three wrong codes and the device must scan again.
- **A notification for each new device**: the computer shows "New device paired" with its name (Windows, macOS, Linux), and so does Athanor's window. If it is not yours, ✕ removes it on the *Remote* page.
- **cloudflared just downloaded is started even while the antivirus reads it**: on Windows a program just written can be refused for a few seconds ("Access is denied"); Athanor now tries again for up to 30 seconds instead of showing an error.

## Nouveautés de la 2.32.1

- **Appairer un appareil demande maintenant d'être devant l'ordinateur** : scanner le QR code n'ouvre qu'une demande. L'appareil demande ensuite un code à 6 chiffres que la page *À distance* n'affiche que sous la souris (d'un tap sur un écran tactile), renouvelé toutes les 20 secondes. Une photo ou une capture du QR code ne fait donc entrer personne ; après trois codes faux, l'appareil doit scanner à nouveau.
- **Une notification pour chaque nouvel appareil** : l'ordinateur affiche « Nouvel appareil appairé » avec son nom (Windows, macOS, Linux), tout comme la fenêtre d'Athanor. Si ce n'est pas le vôtre, ✕ le retire sur la page *À distance*.
- **cloudflared tout juste téléchargé démarre même pendant que l'antivirus le lit** : sous Windows, un programme qui vient d'être écrit peut être refusé quelques secondes (« Accès refusé ») ; Athanor réessaie maintenant jusqu'à 30 secondes au lieu d'afficher une erreur.
