## What's new in 2.24.17

The GitHub push no longer needs Python (the move of Athanor to Go, step 2.2, first part).

- **`athanor github`**: the secret check of the commits before a push, the workshop file that asks Claude to remove a secret (`.athanor/SECRETS_FOUND.md`) and the commit hook that removes Claude as co-author are now done by Athanor's executable. `system/github.sh` uses it when the executable runs on this PC, otherwise the Python as before (`ATHANOR_OUTILS=python` forces the Python).
- Same results as the Python: the same secrets found (same places, same kinds), the same refusals when the commits cannot be read to the end, and never a file written through a link Claude could have put in the project.
- **Checked**: about a thousand lines with secrets and their edges, real `git log` output (binary files, renames, unusual names), the workshop file and the hook against links, and real pushes to a local SSH server standing for GitHub (blocked, pushed anyway, up to date, workflows), with and without Python on the PC.

## Nouveautés de la 2.24.17

Le push vers GitHub n'a plus besoin de Python (passage d'Athanor en Go, étape 2.2, première partie).

- **`athanor github`** : la vérification des secrets dans les commits avant un push, le fichier de l'atelier qui demande à Claude de retirer un secret (`.athanor/SECRETS_FOUND.md`) et le crochet de commit qui retire Claude des co-auteurs sont maintenant faits par l'exécutable d'Athanor. `system/github.sh` s'en sert quand l'exécutable tourne sur ce PC, sinon il garde le Python comme avant (`ATHANOR_OUTILS=python` force le Python).
- Mêmes résultats que le Python : les mêmes secrets trouvés (mêmes endroits, mêmes types), les mêmes refus quand les commits ne se lisent pas jusqu'au bout, et jamais un fichier écrit à travers un lien que Claude aurait pu poser dans le projet.
- **Vérifié** : un millier de lignes avec des secrets et leurs cas limites, de vraies sorties de `git log` (fichiers binaires, renommages, noms inhabituels), le fichier de l'atelier et le crochet face aux liens, et de vrais push vers un serveur SSH local qui joue GitHub (bloqué, poussé quand même, à jour, workflows), avec et sans Python sur le PC.
