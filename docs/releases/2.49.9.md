## What's new in 2.49.9

- **A library of sub-agents.** Your own sub-agents no longer belong to one project or to all of them: they live in a library kept in Athanor, and each project switches on the ones it uses, like the skills.
  - The Team page lists the library: a switch per sub-agent for the current project, **Edit** (the change applies to every project that uses it) and **Delete** (it leaves every project). **+ New sub-agent**, and **Add to the team** on a card Claude proposes in Chat, save it in the library and switch it on in the current project.
  - A sub-agent the lead proposes joins the library too, switched on in its project; another project can switch it on. One switched off or deleted is never proposed again in that project.
  - **24 sub-agents switched on per project** (12 before); the library itself has no limit.
  - Nothing to do for the sub-agents you already have: at the first start they join the library, one made for all your projects switched on in each of them, one of a project in that project. Two different ones with the same name in two projects: the second is renamed (`name-2`). A project moved to another folder keeps its sub-agents; a project removed from Athanor leaves them in the library.

## Nouveautés de la 2.49.9

- **Une bibliothèque de sous-agents.** Vos propres sous-agents n'appartiennent plus à un projet ou à tous : ils sont rangés dans une bibliothèque gardée dans Athanor, et chaque projet active ceux qu'il utilise, comme les skills.
  - La page *Équipe* liste la bibliothèque : un interrupteur par sous-agent pour le projet courant, **Modifier** (la modification vaut pour chaque projet qui l'utilise) et **Supprimer** (il quitte tous les projets). **+ Nouveau sous-agent**, et **Ajouter à l'équipe** sur une fiche que Claude propose dans *Discuter*, l'enregistrent dans la bibliothèque et l'activent dans le projet courant.
  - Un sous-agent que le chef propose rejoint aussi la bibliothèque, activé dans son projet ; un autre projet peut l'activer. Désactivé ou supprimé, il n'est plus jamais reproposé dans ce projet.
  - **24 sous-agents activés par projet** (12 avant) ; la bibliothèque elle-même n'a pas de limite.
  - Rien à faire pour les sous-agents que vous avez déjà : au premier démarrage ils rejoignent la bibliothèque, celui fait pour tous vos projets activé dans chacun, celui d'un projet dans ce projet. Deux différents du même nom dans deux projets : le second est renommé (`nom-2`). Un projet déplacé dans un autre dossier garde ses sous-agents ; un projet retiré d'Athanor les laisse dans la bibliothèque.
