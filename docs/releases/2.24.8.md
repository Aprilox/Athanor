## What's new in 2.24.8

Move to Go, step 1.2: Claude's guards and settings.

- **`athanor hook fichiers`** (Claude's file tools only inside the project and `$TOOLS`, the kit read-only, never inside `.git` nor Claude Code's settings) and **`athanor hook bash`** (no wait of more than 2 minutes, no closing Studio or Unreal by program name) replace `guard.py` and `bash_guard.py`: the same decisions and the same messages, without starting Python at every file Claude reads.
- **`athanor reglages`** writes Claude's settings for each cycle and each parallel worker (replaces `settings.py`), and **`athanor chat settings`** the app chat's (replaces `chat.py`); the hooks they declare are then the Go ones.
- As before, the pilot and the chat use them only when the kit's executable runs on this system and knows them; otherwise, or with `ATHANOR_OUTILS=python`, the Python scripts.
- **Checked against the scripts**: about 800 file-tool calls (links in and out of the project, `..`, `~`, `.git`, `.claude`, `.mcp.json`, read-only folders, Glob patterns, broken input) and 40 commands give the same decision and message; the settings are the same but for the hooks' program; in the pilot's test bench, the hooks written into the settings are run as Claude Code runs them.

## Nouveautés de la 2.24.8

Passage à Go, étape 1.2 : les gardes et les réglages de Claude.

- **`athanor hook fichiers`** (les outils de fichiers de Claude seulement dans le projet et `$TOOLS`, le kit en lecture seule, jamais dans `.git` ni dans les réglages de Claude Code) et **`athanor hook bash`** (pas d'attente de plus de 2 minutes, pas de fermeture de Studio ou d'Unreal par nom de programme) remplacent `guard.py` et `bash_guard.py` : mêmes décisions, mêmes messages, sans lancer Python à chaque fichier que Claude lit.
- **`athanor reglages`** écrit les réglages de Claude pour chaque cycle et chaque ouvrier parallèle (remplace `settings.py`), et **`athanor chat settings`** ceux du chat de l'application (remplace `chat.py`) ; les gardes qu'ils déclarent sont alors celles en Go.
- Comme avant, le pilote et le chat ne s'en servent que si l'exécutable du kit tourne sur ce système et les connaît ; sinon, ou avec `ATHANOR_OUTILS=python`, les scripts Python.
- **Vérifiés contre les scripts** : environ 800 appels d'outils de fichiers (liens vers l'intérieur et l'extérieur du projet, `..`, `~`, `.git`, `.claude`, `.mcp.json`, dossiers en lecture seule, motifs Glob, entrées cassées) et 40 commandes donnent la même décision et le même message ; les réglages sont identiques sauf le programme des gardes ; dans le banc d'essai du pilote, les gardes écrites dans les réglages sont lancées comme Claude Code les lance.
