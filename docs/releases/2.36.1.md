## What's new in 2.36.1

- **Words are optional**: when no running computer has the word a milestone needs (nobody declared anything, *Remote › This computer, for the other computers* left empty), Athanor shares that milestone out like the others, in the plan's order, instead of keeping it for last. It waits behind the others only when a computer of the team that has the word is away for now.
- **Ignored files never overwritten**: when a computer comes back and puts its work aside because another one took its milestone over, its files ignored by git that the team's version replaces are first copied into Athanor's data for the project, and the log says where.
- **No more `on: delete` workflows**: a computer's unfinished work now lives on one branch of its own (`athanor/encours/<computer>`, one patch per milestone), emptied when done but never deleted; a computer that leaves the team marks itself as gone instead of deleting its presence branch. GitHub's `on: delete` workflows no longer run because of Athanor. The computer that goes on from another's work sends its own right away, which holds both.
- **The first-launch tour** now shows the Remote page, joining a project from several computers, and the Guide.

## Nouveautés de la 2.36.1

- **Les mots sont facultatifs** : si aucun ordinateur en marche n'a le mot dont un jalon a besoin (personne n'a rien déclaré, *À distance › Cet ordinateur, pour les autres ordinateurs* laissé vide), Athanor répartit ce jalon comme les autres, dans l'ordre du plan, au lieu de le garder pour la fin. Il passe après les autres seulement si un ordinateur de l'équipe qui a ce mot est absent pour l'instant.
- **Les fichiers ignorés ne sont plus écrasés** : quand un ordinateur revient et met son travail de côté parce qu'un autre a repris son jalon, ses fichiers ignorés par git que la version de l'équipe remplace sont d'abord copiés dans les données d'Athanor pour le projet, et le journal dit où.
- **Plus de workflows `on: delete`** : le travail inachevé d'un ordinateur vit maintenant sur une seule branche à lui (`athanor/encours/<ordinateur>`, un patch par jalon), vidée une fois fini mais jamais supprimée ; un ordinateur qui quitte l'équipe se marque comme parti au lieu de supprimer sa branche de présence. Les workflows `on: delete` de GitHub ne tournent plus à cause d'Athanor. L'ordinateur qui reprend le travail d'un autre envoie aussitôt le sien, qui contient les deux.
- **La visite du premier lancement** montre maintenant la page À distance, le travail à plusieurs ordinateurs, et le Guide.
