## What's new in 2.20.0

- **Athanor's own title bar.** The white Windows bar at the top of the window is gone: a dark bar in the application's colors (its theme and accent) takes its place. It shows the current project and its state, and the buttons to look at what Claude is showing:
  - *View Claude's desktop*, when Claude's desktop is on (in both modes);
  - *Claude's Linux screen*, in the WSL mode with the isolated desktop.
- Everything Windows does with a title bar still works: drag it to move the window (with snapping to the edges and to the top), double-click it to maximize, right-click it for the window menu, resize from the top edge, and hover *Maximize* for Windows 11's snap layouts.
- **Athanor's own dialog when you close it while native pilots run**, instead of Windows' box: *Keep them running* (in the background), *Stop them*, or *Cancel* to keep the window open. Should the page not answer, Windows' box asks as before.
- If the page cannot draw its bar (Windows before 10, a page that does not load), the Windows title bar comes back by itself after a few seconds.
- The native Windows mode's guide tells Claude its commands already start in the project folder: no more failed `cd` at the start of each cycle.

## Nouveautés de la 2.20.0

- **La barre de titre d'Athanor.** La barre blanche de Windows en haut de la fenêtre disparaît : une barre sombre aux couleurs de l'application (son thème et son accent) la remplace. Elle montre le projet en cours et son état, et les boutons pour voir ce que Claude affiche :
  - *Voir le bureau Claude*, quand le bureau Claude est activé (dans les deux modes) ;
  - *Écran Linux de Claude*, en mode WSL avec le bureau isolé.
- Tout ce que Windows fait avec une barre de titre marche toujours : la faire glisser déplace la fenêtre (avec l'ancrage aux bords et en haut), un double-clic l'agrandit, un clic droit ouvre le menu de la fenêtre, le bord du haut la redimensionne, et le survol d'*Agrandir* montre les dispositions d'ancrage de Windows 11.
- **La fenêtre d'Athanor pose elle-même la question quand on la ferme pendant que des pilotes natifs tournent**, au lieu de la boîte de Windows : *Continuer en arrière-plan*, *Les arrêter*, ou *Annuler* pour garder la fenêtre ouverte. Si la page ne répond pas, la boîte de Windows pose la question comme avant.
- Si la page ne peut pas dessiner sa barre (Windows antérieur à 10, page qui ne charge pas), la barre de titre de Windows revient d'elle-même au bout de quelques secondes.
- Le guide du mode Windows natif dit à Claude que ses commandes partent déjà du dossier du projet : plus de `cd` raté au début de chaque cycle.
