## What's new in 2.25.1

- **Share the workshop on GitHub** (an option of the project's GitHub link, off by default): for a repository shared with someone who goes on with the project in their own Athanor. The plan, the requests, the log and the documents of `.athanor/` go into the commits; never `secrets.env`, the raw logs nor the pilot's state. Your friend pulls, adds the project in Athanor and starts: the pilot takes the plan up where it stopped. Only one pilot at a time on a project. Unticked later, the workshop leaves the next push.
- The CI's Linux tests fixed (a test still copied the former `system/` folder).

## Nouveautés de la 2.25.1

- **Partager l'atelier sur GitHub** (une option de la liaison GitHub du projet, décochée par défaut) : pour un dépôt partagé avec quelqu'un qui reprend le projet dans son propre Athanor. Le plan, les demandes, le journal de bord et les documents de `.athanor/` entrent dans les commits ; jamais `secrets.env`, les journaux bruts ni l'état du pilote. Votre ami fait un `git pull`, ajoute le projet dans Athanor et démarre : le pilote reprend le plan là où il s'était arrêté. Un seul pilote à la fois sur un projet. Décochée plus tard, l'atelier sort du prochain envoi.
- Les tests Linux de la CI corrigés (un test copiait encore l'ancien dossier `system/`).
