## What's new in 2.19.3

- **Native Windows mode: GitHub CLI.** *Install everything* also installs the GitHub CLI (winget `GitHub.cli`), needed to link a project to GitHub; *Setup & health* shows it, and the GitHub link says where to install it in this mode.

---

## Nouveautés de la 2.19.3

- **Mode Windows natif : GitHub CLI.** *Tout installer* installe aussi la GitHub CLI (winget `GitHub.cli`), nécessaire pour relier un projet à GitHub ; *Installation et santé* l'affiche, et la liaison GitHub dit où l'installer dans ce mode.
