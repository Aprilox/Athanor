## What's new in 2.11.0

- **Tasks for you**: what Claude cannot do itself (create an account, pay, receive a code by email or SMS, pass a captcha, generate an API key, buy a domain) becomes a task on the new **For you** page, with the exact steps and links. Meanwhile Claude carries on with everything that does not need it.
- **Answer in one click**: **It's done**, with a text, files and, in a protected field, the keys it asked for (they stay on your PC, in the workshop, never in git); or **Skip: find another way**, and Claude finds a solution without it, guided by your text, and never asks again.
- **Checked right away**: at the start of its next cycle Claude retries what was blocked and tells you on the same card: *Verified ✓*, or what is still missing and how to fix it.
- **A pause instead of turning in circles**: when every remaining milestone waits for you, the pilot pauses (state *Claude is waiting for you*) and starts again as soon as you answer; the waiting time does not count towards the maximum duration.
- **You know at once**: a badge on *For you* in the menu, a banner on *Overview*, a dialog in the window and a system notification.

## Nouveautés de la 2.11.0

- **Des tâches pour vous** : ce que Claude ne peut pas faire lui-même (créer un compte, payer, recevoir un code par e-mail ou SMS, passer un captcha, générer une clé d'API, acheter un domaine) devient une tâche sur la nouvelle page **Pour vous**, avec les étapes exactes et les liens. En attendant, Claude continue tout ce qui n'en dépend pas.
- **Répondre en un clic** : **C'est fait**, avec un texte, des fichiers et, dans un champ protégé, les clés demandées (elles restent sur votre PC, dans l'atelier, jamais dans git) ; ou **Passer : trouve une autre solution**, et Claude trouve une solution sans elle, guidé par votre texte, sans jamais la redemander.
- **Vérifié aussitôt** : au début de son cycle suivant, Claude réessaie ce qui bloquait et vous répond sur la même carte : *Vérifiée ✓*, ou ce qui manque encore et comment le corriger.
- **Une pause plutôt que de tourner en rond** : quand tous les jalons restants vous attendent, le pilote se met en pause (état *Claude vous attend*) et repart dès que vous répondez ; l'attente ne compte pas dans la durée maximale.
- **Vous êtes prévenu tout de suite** : une pastille sur *Pour vous* dans le menu, un bandeau sur *Suivi*, une fenêtre dans l'application et une notification système.
