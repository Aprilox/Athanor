## What's new in 2.24.4

- **First steps that match the system**: on Windows, step 1 lets you choose between WSL (Claude in a sandbox) and native Windows (no WSL); in native mode, Git Bash and Claude Code for Windows count as installed, so the *Start* button and the Overview page appear without WSL. On Linux, Claude Code installed counts as installed, and *Install* opens `commands/install.sh` in a terminal.
- **Setup & health no longer freezes during "Ask Claude"**: the checks and the output refresh in place instead of the whole page every 1.5 s; what you type stays, the output keeps your scroll position and is not rebuilt while you select text in it.

## Nouveautés de la 2.24.4

- **Premiers pas adaptés au système** : sous Windows, l'étape 1 propose WSL (Claude dans une cage) ou Windows natif (sans WSL) ; en mode natif, Git Bash et Claude Code pour Windows suffisent pour que l'outillage soit installé, donc le bouton *Démarrer* et la page Suivi apparaissent sans WSL. Sous Linux, Claude Code installé suffit, et *Installer* ouvre `commands/install.sh` dans un terminal.
- **Installation & santé ne se fige plus pendant « Demander à Claude »** : les vérifications et la sortie se mettent à jour sur place au lieu de toute la page toutes les 1,5 s ; ce que vous tapez reste, la sortie garde votre défilement et n'est pas reconstruite pendant que vous y sélectionnez du texte.
