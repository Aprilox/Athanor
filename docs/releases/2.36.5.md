## What's new in 2.36.5

- **An update cleans older folders up**: an Athanor folder from before 2.25 (a copy of the repository, with its bash and Python scripts) kept files no version uses any more: `commands/`, the scripts of `system/` (`pilot.sh`, `safety.sh`, the `.py`…), `docs/`, the README, `build.cmd`… An update now removes each of them when it is exactly as a version shipped it (Athanor knows every version of them, with LF or CRLF line ends). A file you changed is never lost: it is moved into `logs/ancien-kit/<date>/`. The folders left empty go, and `logs/nettoyage-<date>.txt` lists what went. Your token, settings, projects, `logs/`, `tools/`, `extensions/`, `local/`, the commands of `system/bin` and any file of your own are never touched.

To bring a folder of an older version (whose *Update* button no longer finds the releases) up to date: close Athanor, put the new `Athanor-Windows-x64.exe` in that folder and open it. Athanor stays in that folder, brings it to its version, replaces `Athanor.exe` and cleans up; then delete the downloaded file and open `Athanor.exe` as before. The next updates come from the button.

## Nouveautés de la 2.36.5

- **Une mise à jour fait le ménage dans les anciens dossiers** : un dossier Athanor d'avant la 2.25 (une copie du dépôt, avec ses scripts bash et Python) gardait des fichiers qu'aucune version n'utilise plus : `commands/`, les scripts de `system/` (`pilot.sh`, `safety.sh`, les `.py`…), `docs/`, le README, `build.cmd`… Une mise à jour retire maintenant chacun d'eux s'il est exactement tel qu'une version l'a livré (Athanor connaît toutes leurs versions, avec des fins de ligne LF ou CRLF). Un fichier que vous avez modifié n'est jamais perdu : il est déplacé dans `logs/ancien-kit/<date>/`. Les dossiers devenus vides partent, et `logs/nettoyage-<date>.txt` liste ce qui est parti. Votre jeton, vos réglages, vos projets, `logs/`, `tools/`, `extensions/`, `local/`, les commandes de `system/bin` et vos propres fichiers ne sont jamais touchés.

Pour mettre à jour un dossier d'une ancienne version (dont le bouton *Mettre à jour* ne trouve plus les versions) : fermez Athanor, mettez le nouvel `Athanor-Windows-x64.exe` dans ce dossier et ouvrez-le. Athanor reste dans ce dossier, le met à sa version, remplace `Athanor.exe` et fait le ménage ; supprimez ensuite le fichier téléchargé et ouvrez `Athanor.exe` comme avant. Les mises à jour suivantes passent par le bouton.
