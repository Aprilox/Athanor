## What's new in 2.45.0

- **The team's workshop through the direct link, never on GitHub.** On the master, *Overview → Team, live → Workshop through the direct link*: the plan, the request, the log and the notes go from computer to computer through the master's link, and `.athanor/` leaves the commits on every computer (the next push takes it out of the repository; the files stay in each folder). For a public repository, nothing of the workshop is published any more.
- **Merged file by file between two cycles.** Each pilot merges its workshop with the team's: the notes every computer adds to (`LOG.md`, `BUGS.md`, `TEAM_NOTES.md`…) are joined, the ticked milestones are joined, other text is merged; when two computers changed the same lines, the team's version stays and this computer's goes to `.athanor/merge/`, which Claude folds in first (`.athanor/WORKSHOP_MERGE.md`). A removal never wins over a change. Two computers writing at the same moment: the second merges again, nothing is lost.
- **The nodes wait for the master's workshop.** A computer joining from an empty folder gets the code from GitHub and waits for the request from the master's workshop (the master shares it when its pilot starts, or when it starts the team).
- **Start the whole team from the master.** *Start the team* starts the master's pilot, then every node's within seconds; *Stop the team after the cycle* stops them all at the end of their cycle. A node follows only these two orders, and its user can refuse them (*The master may start and stop this computer's pilot*). Nothing else of a computer is ever driven from another.
- A master out of reach: the nodes keep their workshop and give it to the team when it answers again. Files bigger than 8 MB stay on their computer (put them in the project itself: they go through GitHub).
- A computer that does not share its workshop on GitHub keeps its `.athanor/` files when another computer's commit takes them out of git (they were removed by the merge before).
- In a terminal: **M**, then *Team, live*: the same choices.

## Nouveautés de la 2.45.0

- **L'atelier de l'équipe par le lien direct, jamais sur GitHub.** Sur le maître, *Suivi → Équipe, en direct → Atelier par le lien direct* : le plan, la demande, le journal et les notes passent d'ordinateur en ordinateur par le lien du maître, et `.athanor/` quitte les commits sur chaque ordinateur (le prochain push le retire du dépôt ; les fichiers restent dans chaque dossier). Pour un dépôt public, plus rien de l'atelier n'est publié.
- **Fusionné fichier par fichier entre deux cycles.** Chaque pilote fusionne son atelier avec celui de l'équipe : les notes que chaque ordinateur complète (`LOG.md`, `BUGS.md`, `TEAM_NOTES.md`…) sont réunies, les jalons cochés sont réunis, le reste du texte est fusionné ; quand deux ordinateurs ont changé les mêmes lignes, la version de l'équipe reste et celle de cet ordinateur va dans `.athanor/merge/`, que Claude intègre en premier (`.athanor/WORKSHOP_MERGE.md`). Une suppression ne l'emporte jamais sur une modification. Deux ordinateurs qui écrivent au même moment : le second refusionne, rien n'est perdu.
- **Les nœuds attendent l'atelier du maître.** Un ordinateur qui rejoint depuis un dossier vide reçoit le code par GitHub et attend la demande de l'atelier du maître (le maître la partage quand son pilote démarre, ou quand il lance l'équipe).
- **Lancer toute l'équipe depuis le maître.** *Lancer l'équipe* lance le pilote du maître, puis celui de chaque nœud en quelques secondes ; *Arrêter l'équipe après le cycle* les arrête tous à la fin de leur cycle. Un nœud ne suit que ces deux ordres, et son utilisateur peut les refuser (*Le maître peut lancer et arrêter le pilote de cet ordinateur*). Rien d'autre d'un ordinateur n'est jamais piloté depuis un autre.
- Un maître injoignable : les nœuds gardent leur atelier et le donnent à l'équipe quand il répond de nouveau. Les fichiers de plus de 8 Mo restent sur leur ordinateur (mettez-les dans le projet lui-même : ils passent par GitHub).
- Un ordinateur qui ne partage pas son atelier sur GitHub garde ses fichiers `.athanor/` quand le commit d'un autre ordinateur les sort de git (la fusion les supprimait avant).
- Dans un terminal : **M**, puis *Équipe, en direct* : les mêmes choix.
