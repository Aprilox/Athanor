## What's new in 2.19.4

- **Native Windows mode: no more "rename … Access is denied".** The same command started twice (a status check while the previous one still runs) tried to replace its script file while Git Bash had it open, which Windows refuses. The file, named after its content, is now reused as it is.

---

## Nouveautés de la 2.19.4

- **Mode Windows natif : plus de « rename … Access is denied ».** La même commande lancée deux fois (une vérification d'état pendant que la précédente tourne encore) essayait de remplacer son fichier de script pendant que Git Bash l'avait ouvert, ce que Windows refuse. Le fichier, nommé d'après son contenu, est maintenant réutilisé tel quel.
