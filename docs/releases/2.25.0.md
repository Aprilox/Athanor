## What's new in 2.25.0

**Athanor is now entirely Go: no bash, PowerShell or Python script is left in the tool.** Everything it does is a command of its executable (`Athanor.exe` on Windows, `athanor` on Linux and macOS): `athanor aide` lists them.

- **The pilot** starts with `athanor demarrer`, which watches over it: after an internal error of its own, it stops the Claude sessions left behind and starts the pilot again 30 s later (three times an hour at most), keeping the report. Stopping: `athanor arreter` (now, or `--apres-cycle`), following: `athanor suivre`.
- **Native Windows**: the pilot is `Athanor.exe` itself (no Git Bash in between), and the programs it starts no longer open console windows. **Fix:** every cycle of the native Windows pilot could be counted as an error (its log stayed empty): the log is no longer opened in append-only mode, which some programs could not write to.
- **Claude's commands** (`blender`, `tool`, `unreal-editor`, `roblox-studio`, `pc-exec`, `install-windows`, `adb`, `windows-var`, `athanor`…) are the executable under other names: links made by the pilot in `system/bin` (Linux, WSL) or `system/bin-windows` (native Windows).
- **GitHub**: linking a project is in Go too, on every system.
- **Windows installers** (`installer-windows`, `installer-natif`), the administrator task (`autoriser-admin`, `admin-tache`) and Unreal's network (`reseau-unreal`, `relais-unreal`) are Go. The administrator task now runs a copy of Athanor.exe kept in `C:\ProgramData\Athanor` (readable, not writable, by your account): Setup & health says when a task made by an older version must be allowed again (one UAC prompt).
- **Setup & health** runs no script: each check is `athanor sante ID`, each repair a command (a Claude repair: `athanor reparation`, the sandbox test: `athanor tester-cage`).
- **Your projects stay clean**: Athanor no longer writes into a project's `.gitignore` nor `.claude/` (`.git/info/exclude` keeps `.athanor/` and the local secrets out of git). Delete `.athanor/` and the project is as you left it.
- **macOS**: a step-by-step section in the README; the CI's macOS and Windows tests fixed.
- From the source code: `cd app && go run . construire` (replaces `build.sh` / `build.cmd`).
- `PILOT_ENGINE` is gone (a single pilot).

## Nouveautés de la 2.25.0

**Athanor est désormais entièrement en Go : plus aucun script bash, PowerShell ou Python dans l'outil.** Tout ce qu'il fait est une commande de son exécutable (`Athanor.exe` sous Windows, `athanor` sous Linux et macOS) : `athanor aide` les liste.

- **Le pilote** démarre avec `athanor demarrer`, qui veille sur lui : après une erreur interne, il arrête les sessions Claude restées en route et relance le pilote 30 s plus tard (trois fois par heure au plus), en gardant le rapport. Arrêter : `athanor arreter` (tout de suite, ou `--apres-cycle`), suivre : `athanor suivre`.
- **Windows natif** : le pilote est `Athanor.exe` lui-même (plus de Git Bash entre les deux), et les programmes qu'il lance n'ouvrent plus de fenêtres de console. **Correction :** chaque cycle du pilote Windows natif pouvait être compté en erreur (son journal restait vide) : le journal n'est plus ouvert en « ajout seul », mode où certains programmes ne pouvaient pas écrire.
- **Les commandes de Claude** (`blender`, `tool`, `unreal-editor`, `roblox-studio`, `pc-exec`, `install-windows`, `adb`, `windows-var`, `athanor`…) sont l'exécutable sous d'autres noms : des liens créés par le pilote dans `system/bin` (Linux, WSL) ou `system/bin-windows` (Windows natif).
- **GitHub** : la liaison d'un projet est elle aussi en Go, sur tous les systèmes.
- **Les installateurs Windows** (`installer-windows`, `installer-natif`), la tâche administrateur (`autoriser-admin`, `admin-tache`) et le réseau d'Unreal (`reseau-unreal`, `relais-unreal`) sont en Go. La tâche administrateur lance désormais une copie d'Athanor.exe gardée dans `C:\ProgramData\Athanor` (lisible, pas modifiable, par votre compte) : *Installation & santé* signale quand une tâche créée par une version précédente doit être autorisée à nouveau (une demande UAC).
- **Installation & santé** ne lance plus aucun script : chaque contrôle est `athanor sante ID`, chaque réparation une commande (une réparation par Claude : `athanor reparation`, le test de la barrière : `athanor tester-cage`).
- **Vos projets restent propres** : Athanor n'écrit plus dans le `.gitignore` d'un projet ni dans `.claude/` (`.git/info/exclude` garde `.athanor/` et les secrets locaux hors de git). Supprimez `.athanor/` et le projet est tel que vous l'avez laissé.
- **macOS** : une section pas à pas dans le README ; les tests macOS et Windows de la CI corrigés.
- Depuis le code source : `cd app && go run . construire` (remplace `build.sh` / `build.cmd`).
- `PILOT_ENGINE` disparaît (un seul pilote).
