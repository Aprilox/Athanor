## What's new in 2.53.0

- **Models, project by project**: Manage › Working mode has a new Models block with the six models of Settings › Claude (the lead, the fallback, the framing, the parallel workers, the sub-agents, the cheap model). Each one is "Like Settings" by default, its current value shown in it, or a model of your choice for this project only: Opus for one large project, Sonnet or Haiku for a small one, without touching the others.
- **Applied at the next cycle, no restart**: the pilot reads the project's models at the start of each cycle, like the working modes, and writes in its log which ones it uses. A change made during a cycle shows as waiting until the next cycle has really read it.
- The same block is on the New project page, beside the form: the models chosen there are given to the project when it is created.
- The Team page shows the project's own models for the lead and the sub-agents.
- Only model names are kept (an alias, a full name, a cloud provider's id; "auto" only for the sub-agents): the file is in the project's workshop, and a value is never passed to Claude Code as an option.

## Nouveautés de la 2.53.0

- **Les modèles, projet par projet** : Gérer › Mode de travail a un nouveau bloc Modèles avec les six modèles de Réglages › Claude (le chef, le secours, le cadrage, les ouvriers parallèles, les sous-agents, le modèle économique). Chacun est « Comme les Réglages » par défaut, sa valeur actuelle affichée dedans, ou un modèle de votre choix pour ce projet seulement : Opus pour un gros projet, Sonnet ou Haiku pour un petit, sans toucher aux autres.
- **Appliqué au prochain cycle, sans redémarrage** : le pilote lit les modèles du projet au début de chaque cycle, comme les modes de travail, et écrit dans son journal ceux qu'il utilise. Un changement fait pendant un cycle s'affiche en attente tant que le cycle suivant ne l'a pas réellement lu.
- Le même bloc est sur la page Nouveau projet, à côté du formulaire : les modèles choisis là sont donnés au projet à sa création.
- La page Équipe affiche les modèles propres au projet pour le chef et les sous-agents.
- Seuls des noms de modèles sont gardés (un alias, un nom complet, un identifiant de fournisseur cloud ; « auto » seulement pour les sous-agents) : le fichier est dans l'atelier du projet, et une valeur n'est jamais passée à Claude Code comme une option.
