## What's new in 2.19.1

- **Native Windows mode: Claude Code kept up to date.** *Install everything* now updates a Claude Code for Windows that was already installed (an old one does not know the latest models: "unrecognized_model"), and *Setup & health* says when it is too old for this mode.

---

## Nouveautés de la 2.19.1

- **Mode Windows natif : Claude Code tenu à jour.** *Tout installer* met maintenant à jour un Claude Code pour Windows déjà installé (une ancienne version ne connaît pas les derniers modèles : « unrecognized_model »), et *Installation et santé* signale quand il est trop ancien pour ce mode.
