## What's new in 3.1.7

- **A fresh session beyond 200k tokens by default, or auto**: `RELAY_CONTEXT_K` now defaults to 200 (it was 110), and `auto` picks it for each project at each cycle from its own finished milestones (what three in four of them needed, plus a margin, between 110k and 300k). The project's *Usage* then shows the threshold used on average. A value already saved in Settings is kept.
- **Milestones sized for one session**: the framing knows the context a session may reach and splits what would not fit; after a relay, the fresh session first splits what is left of a milestone too big for one session.
- **Where things stand, at the start of each cycle**: the pilot gives Claude the next milestone, the last commits, what is not committed and the last full check, so that a fresh session no longer spends its first minutes finding them out, nor runs a check only to see where things stand.
- **The slow commands, shown to Claude**: the commands that cost the most time in the last cycle (checks, builds, test runs) are listed in the next one, which makes them faster without testing less, or notes why they cannot be.
- **No full check run again for nothing**: a full check that already passed on exactly the same state of the project is refused, with its result; any change lets it run again, and a failed check can always be run again.
- **Unused tools offered for removal**: each cycle notes which folders of `tools/` it uses, and Setup & health lists those of 1 GB or more that no project used for 30 days. One goes only on your click, and is downloaded again the day a project needs it.
- **RTK and Ponytail, the same on every Athanor**: Setup & health brings an RTK older than this Athanor's version back to it, and says when a newer RTK or Ponytail exists upstream: it comes with an update of Athanor, once checked, never on one computer alone.
- **Releases**: their notes are checked for GitHub mentions before anything is published (an `@name` outside code); the macOS test that failed now and then on a random folder name is fixed; the README gives RTK's licence (Apache 2.0).

## Nouveautés de la 3.1.7

- **Une nouvelle session au-delà de 200k tokens par défaut, ou auto** : `RELAY_CONTEXT_K` vaut maintenant 200 par défaut (110 avant), et `auto` le choisit pour chaque projet à chaque cycle d'après ses propres jalons terminés (ce qu'il a fallu à trois sur quatre, plus une marge, entre 110k et 300k). La *Consommation* du projet affiche alors le seuil utilisé en moyenne. Une valeur déjà enregistrée dans les Réglages est gardée.
- **Des jalons à la taille d'une session** : le cadrage connaît le contexte qu'une session peut atteindre et découpe ce qui n'y tiendrait pas ; après un relais, la nouvelle session découpe d'abord ce qui reste d'un jalon trop gros pour une seule session.
- **Où en est le projet, au début de chaque cycle** : le pilote donne à Claude le prochain jalon, les derniers commits, ce qui n'est pas commité et la dernière vérification complète, pour qu'une nouvelle session ne passe plus ses premières minutes à les retrouver, ni ne lance une vérification seulement pour voir où en est le projet.
- **Les commandes lentes, montrées à Claude** : les commandes qui ont coûté le plus de temps au dernier cycle (vérifications, compilations, tests) sont listées au suivant, qui les rend plus rapides sans tester moins, ou note pourquoi elles ne peuvent pas l'être.
- **Plus de vérification complète relancée pour rien** : une vérification complète déjà réussie sur exactement le même état du projet est refusée, avec son résultat ; le moindre changement la laisse repasser, et une vérification qui a échoué peut toujours être relancée.
- **Les outils inutilisés proposés au ménage** : chaque cycle note les dossiers de `tools/` qu'il utilise, et Installation et santé liste ceux de 1 Go ou plus qu'aucun projet n'a utilisés depuis 30 jours. Un dossier ne part que sur votre clic, et se télécharge de nouveau le jour où un projet en a besoin.
- **RTK et Ponytail, les mêmes sur chaque Athanor** : Installation et santé ramène un RTK plus ancien que celui de cette version d'Athanor à sa version, et signale quand un RTK ou un Ponytail plus récent existe en amont : il arrive avec une mise à jour d'Athanor, une fois vérifié, jamais sur un seul ordinateur.
- **Les releases** : leurs notes sont vérifiées avant toute publication (une mention GitHub `@nom` hors code les arrête) ; le test macOS qui échouait de temps en temps sur un nom de dossier tiré au hasard est corrigé ; le README donne la licence de RTK (Apache 2.0).
