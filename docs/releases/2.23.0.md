## What's new in 2.23.0

- **Automatic stop on the quota** (Overview → *Subscription quota*): for the 5-hour session, the week, and a model's own week (Fable) when Claude Code reports one, choose a threshold (50 to 95 %) and what the pilots do when it is reached:
  - *stop after the cycle*: the current milestone finishes, then the pilot stops;
  - *stop now*: the cycle is cut at once (checked every minute), then the pilot stops;
  - *pause until the reset*: the pilot waits for the window to reset, then goes on by itself.
- The rule applies to every pilot of the PC (the quota is the account's), at once, without restarting them; a red mark shows the threshold on the bar.

## Nouveautés de la 2.23.0

- **Arrêt automatique sur le quota** (Suivi → *Quota de l'abonnement*) : pour la session de 5 h, la semaine, et la semaine propre à un modèle (Fable) quand Claude Code en indique une, choisissez un seuil (de 50 à 95 %) et ce que font les pilotes quand il est atteint :
  - *arrêt après le cycle* : le jalon en cours se termine, puis le pilote s'arrête ;
  - *arrêt immédiat* : le cycle est coupé tout de suite (vérifié chaque minute), puis le pilote s'arrête ;
  - *pause jusqu'à la réinitialisation* : le pilote attend que la fenêtre se réinitialise, puis reprend tout seul.
- La règle vaut pour tous les pilotes du PC (le quota est celui du compte), tout de suite, sans les redémarrer ; un trait rouge marque le seuil sur la barre.
