## What's new in 2.24.21

A simpler first launch, projects that carry on where they were, a Team page that shows what each agent is doing, and a GitHub block that never stays on "Loading…".

- **Start is always there.** If the tooling was never seen installed, a dialog asks whether it was installed, with "Install it now", "Open the check" and "Start anyway".
- **Native Windows by default** on a fresh install (nothing else to install); WSL stays one click away.
- **Setup & health has one tab per mode** (Native Windows and WSL on Windows, Linux on Linux), the current one marked: each tab says what the mode is, installs everything it needs, and switches to it. The first steps keep a single "Install everything" button for the current mode. The sandbox test is hidden in native Windows (no sandbox there).
- **A guided tour** after the first-launch wizard: the mode, Setup & health, a new project, Start.
- **Projects stopped in the middle or brought from another PC** carry on with their plan: git locks left by a stop are removed, uncommitted work and paths of the other PC are written for Claude (`.athanor/RESUME.md`, handled before any new work), and the ticked milestones are checked against the folder (`REVERIFY`). Never a new framing.
- **Team**: each agent's latest actions live, "last action N ago", and the lead's status follows the pilot's phase: a long build or test run no longer looks like a hang.
- **GitHub**: create a repository or use one of yours, commit without Claude as co-author, **Test the connection** (Athanor's key, the branch, a dry-run push), and **Save and push the work in progress** (a commit "M3: … (in progress)", then the push, without Claude: it works with no quota left). Every call to WSL has a time limit, the last known state shows at once, and the block no longer stays on "Loading…" when the page builds slowly.

## Nouveautés de la 2.24.21

Un premier lancement plus simple, des projets qui reprennent là où ils en étaient, une page Équipe qui montre ce que fait chaque agent, et un bloc GitHub qui ne reste plus sur « Chargement… ».

- **Démarrer est toujours là.** Si l'outillage n'a jamais été vu installé, une fenêtre demande s'il l'a bien été, avec « Installer maintenant », « Ouvrir la vérification » et « Démarrer quand même ».
- **Windows natif par défaut** sur une installation neuve (rien d'autre à installer) ; WSL reste à un clic.
- **Installation & santé a un onglet par mode** (Windows natif et WSL sous Windows, Linux sous Linux), l'actuel marqué : chaque onglet dit ce qu'est le mode, installe tout ce qu'il lui faut et y bascule. Les premières étapes gardent un seul bouton « Tout installer » pour le mode actuel. Le test du bac à sable est masqué en Windows natif (pas de bac à sable).
- **Une visite guidée** après l'assistant du premier lancement : le mode, Installation & santé, un nouveau projet, Démarrer.
- **Les projets arrêtés en plein milieu ou venus d'un autre PC** reprennent leur plan : les verrous git laissés par un arrêt sont retirés, le travail non commité et les chemins de l'autre PC sont écrits pour Claude (`.athanor/RESUME.md`, traité avant tout nouveau travail), et les jalons cochés sont revérifiés contre le dossier (`REVERIFY`). Jamais de nouveau cadrage.
- **Équipe** : les dernières actions de chaque agent en direct, « dernière action il y a N », et l'état du chef suit la phase du pilote : une longue compilation ou des tests ne ressemblent plus à un blocage.
- **GitHub** : créer un dépôt ou utiliser un des vôtres, commiter sans Claude en co-auteur, **Tester la connexion** (la clé d'Athanor, la branche, un push à blanc), et **Enregistrer et pousser le travail en cours** (un commit « M3 : … (in progress) », puis le push, sans Claude : ça marche sans quota). Chaque appel à WSL a un délai, le dernier état connu s'affiche tout de suite, et le bloc ne reste plus sur « Chargement… » quand la page se construit lentement.
