## What's new in 2.39.0

- **GitHub goes through the computer's connection, always**: linking a project needs *Settings → Options → GitHub → Connect to GitHub* (once per computer). A repository no longer gets a key of its own: *Use one of my repositories* links with no window, and *Create a private repository* signs in once to create it, then pushes with the connection. Until the computer is connected, the GitHub block, *New project* and *Join a project* say so, with a *Connect to GitHub* button. A project linked by an older version with its own key keeps pushing with it, and *Use my GitHub connection* moves it over.
- **Buttons that take you there**: the Guide's GitHub and *Several computers* steps each have a button that opens the right page and lights up the block (*Settings → Options → GitHub*, *Manage → GitHub*, *Overview → Other computers*, *Join a project*).
- **Several computers, step by step**: the Guide and the *Other computers* block now go through it in order: who can take part (anyone with write access to the repository: no organization needed), connecting each computer, the switch on the first one, *Join a project* on the others.
- **README refreshed**: GitHub and several computers rewritten for the connection, new screenshots of the current app.

## Nouveautés de la 2.39.0

- **GitHub passe toujours par la connexion de l'ordinateur** : lier un projet demande *Réglages → Options → GitHub → Se connecter à GitHub* (une fois par ordinateur). Un dépôt n'a plus de clé à lui : *Utiliser un de mes dépôts* lie sans fenêtre, et *Créer un dépôt privé* se connecte une fois pour le créer, puis envoie avec la connexion. Tant que l'ordinateur n'est pas connecté, le bloc GitHub, *Nouveau projet* et *Rejoindre un projet* le disent, avec un bouton *Se connecter à GitHub*. Un projet lié par une ancienne version avec sa propre clé continue d'envoyer avec elle, et *Utiliser ma connexion GitHub* le fait passer à la connexion.
- **Des boutons qui y mènent** : les étapes GitHub et *Plusieurs ordinateurs* du Guide ont chacune un bouton qui ouvre la bonne page et éclaire le bloc (*Réglages → Options → GitHub*, *Gérer → GitHub*, *Suivi → Autres ordinateurs*, *Rejoindre un projet*).
- **Plusieurs ordinateurs, pas à pas** : le Guide et le bloc *Autres ordinateurs* le déroulent dans l'ordre : qui peut participer (toute personne ayant l'accès en écriture au dépôt : pas besoin d'organisation), la connexion de chaque ordinateur, l'interrupteur sur le premier, *Rejoindre un projet* sur les autres.
- **README revu** : GitHub et plusieurs ordinateurs réécrits pour la connexion, nouvelles captures de l'application actuelle.
