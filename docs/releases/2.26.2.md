## What's new in 2.26.2

- **Rebuild Athanor keeps the updates**: an executable rebuilt on the PC (*Setup & health → Rebuild Athanor*, a repair by Claude) carries the kit's files like a release, so it still updates itself from the app (before, it lost that).
- **Settings › Options › Athanor's folder** shows the folder instead of an editable field; using another tool folder moves under *advanced*.
- **Starting with the computer** says what it does on each system (Windows, your Linux desktop session, logging in to the Mac).
- The interface's translations lose the sentences no longer used (a lighter app).

## Nouveautés de la 2.26.2

- **Recompiler Athanor garde les mises à jour** : un exécutable recompilé sur le PC (*Installation & santé → Recompiler Athanor*, une réparation par Claude) porte les fichiers du kit comme une version publiée, et se met donc toujours à jour depuis l'application (avant, il perdait cette possibilité).
- **Réglages › Options › Dossier d'Athanor** montre le dossier au lieu d'un champ modifiable ; utiliser un autre dossier d'outil passe en *avancé*.
- **Le démarrage avec l'ordinateur** dit ce qu'il fait sur chaque système (Windows, votre session de bureau Linux, l'ouverture de session sur le Mac).
- Les traductions de l'interface perdent les phrases qui ne servent plus (une application plus légère).
